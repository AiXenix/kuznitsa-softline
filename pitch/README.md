# Презентация для жюри

Пятиминутная презентация «Кузницы Softline» для жюри хакатона «ИИкузница».

- В браузере: `/web/pitch/index.html` на стенде (https://kuznitsa.45-141-37-218.sslip.io:8443/web/pitch/index.html).
- В PDF: `/web/pitch/kuznitsa-pitch.pdf`, 20 страниц: живые слайды разложены по шагам.
- Текст выступления, план по времени, клавиши и ответы на вероятные вопросы — [SPEECH.md](SPEECH.md).
- Как устроен поиск простыми словами: нормализация, источники слов, что вручную и что автоматически, почему Jev — [HOW-IT-WORKS.md](HOW-IT-WORKS.md).

Презентация — один самодостаточный HTML-файл на 14 слайдов: шрифты, картинки и снимок ответов стенда вшиты внутрь. На стенде слайды 3, 5, 6 и 7 обращаются к `/api/search` и `/api/suggest` вживую, плитки слайдов 4 и 8 отправляют запрос на живой слайд 3. Из файла, в режиме печати (`?print=1`) или без связи со стендом показывается снимок ответов стенда от 27.11.

## Сборка

Нужны Node.js 22 и Google Chrome. Python с Pillow нужен только для контактных листов.

```
node build/build.js                       # → build/dist/index.html
node build/shot.js --url file:///…/build/dist/index.html --out shots --steps all \
     --pdf build/dist/slides.pdf --pages pages   # снимки всех шагов, PDF и его страницы картинками
node build/md2pdf.js SPEECH.md SPEECH.pdf # текст выступления в PDF
```

Проверки:

- `node build/serve.js 47631` — раздаёт презентацию и пересылает `/api/*` на стенд, чтобы проверить живой режим локально; `build/livetest.ps1` делает то же и снимает живые шаги.
- `node build/ptest.js <адрес>` — окно суфлёра и клавиши.
- `node build/verify.js` — сверяет подписи на слайдах со снимком ответов стенда.
- `node build/pace.js` — помещается ли текст выступления в план по времени (130 слов в минуту).

## Файлы

| Путь | Что это |
|---|---|
| `build/slides.html` | слайды и текст выступления (`<aside class="notes">`, `data-at` — номер клика) |
| `build/deck.css` | оформление в стиле Softline, шрифт Inter |
| `build/js/00-util.js` | данные, запросы к стенду, снимок, форматирование |
| `build/js/10-engine.js` | шаги, клавиши, таймер, окно суфлёра |
| `build/js/20-live.js` | титул, «Проблема», живое сравнение двух поисков |
| `build/js/30-widgets.js` | плитки, допродажа, подсказки, аналоги, полосы качества, источники слов |
| `data/pitch-data.json` | снимок ответов стенда для показанных запросов |
| `data/pitch-adm.jpg`, `data/pitch-qr.svg` | снимок консоли и QR-код стенда |
| `src/` | шрифты Inter и логотип |
