Каждый такой ответ — потерянный клиент. При пятистах поисках в день это заметные деньги.

Вторая половина задачи — допродажа. Ищем Astra Linux: на первом месте сам продукт, причём по акции. Ниже — «Часто покупают вместе»: антивирус для Linux, резервное копирование, средство защиты, офисный пакет. И у каждой рекомендации написано, почему она здесь.

Допродажа не засоряет выдачу: в основном списке — не больше трёх мест из восьми, не раньше третьего места и не подряд, а «Часто покупают вместе» идёт отдельным блоком. Правил сейчас двести тридцать восемь, менеджер правит их сам, без программиста.

Как это устроено. Запрос проходит конвейер: чистим — раскладка, опечатки, транслит; переводим жаргон по словарям; определяем намерение — товар, раздел, замена, продление; ищем сразу тремя способами — по словам, по буквенным фрагментам и по смыслу; собираем ответ и добавляем допродажу.

Нейросеть подключается только для сложных вопросов. «Как учить сотрудников удалённо»: правила подумали бы про удалённый доступ, модель понимает, что это обучение персонала. Четыре тысячных рубля за вопрос, повтор — из кэша.

Итог: в быстром режиме медиана ответа — пятнадцать миллисекунд, обычный запрос бесплатен, хватает одного сервера без видеокарты.
