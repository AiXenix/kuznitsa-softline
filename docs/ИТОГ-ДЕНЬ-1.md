# Итог дня 1 — 26 ноября 2026

«Кузница Softline», команда AiXenix. Хакатон «ИИкузница», трек «Аналитик данных», задача «Умный поиск на сайте» store.softline.ru.

## Главное

- Поиск работает на настоящем фиде магазина: 136 040 предложений, 11 713 карточек товаров.
- Закрытый набор из 400 запросов покупателя размечал независимый «организатор», который не видел нашего кода. Верная выдача — **91,0 %** в быстром режиме и **94,2 %** в умном. Утром того же дня было 65,0 % и 68,0 %.
- 10 контрольных примеров организаторов — **10 из 10** в обоих режимах.
- Скорость после прогрева: медиана 7 мс, p95 — **54 мс** в быстром режиме и **346 мс** в умном.
- Внешний категоризатор Jev понадобился в 18 % умных запросов. Умный запрос в среднем стоит **≈ 0,001 ₽** (оценка по курсу ~95 ₽/$), быстрый — 0 ₽.

## Что на стенде

- **Витрина в стиле store.softline.ru.** Шапка, каталог, строка поиска, карточки с картинкой, ценой или «Цена по запросу», «Под заказ», «Акция», корзина. По умолчанию включён умный режим.
- **Всё техническое — под шестерёнкой.** Режимы (умный, быстрый и обычный поиск по словам для сравнения), профиль покупателя, «Понято так», трасса со временем каждого шага, сравнение режимов. Покупатель видит просто магазин.
- **Консоль.**
  - *Аналитика «до / после».* Синтетическая история с параметрами задания: 45 000 поисков за 90 дней, 1 119 фраз. Пустые выдачи — 28,6 % → 0 %, нужный товар в первых пяти — 70,9 % → 84,6 %, уходы после неудачи — 11,5 % → 6,6 %, из поиска в заказ — 7,8 % → 9,4 %. Осторожная оценка возвращаемой выручки — 27,9 млн ₽, базовая — 43,4 млн ₽. Это расчёт по модели кликов на синтетической истории. Реальные значения подставятся из Метрики организаторов.
  - *Допродажи.* 233 правила, кнопки «Новое правило» и «Изменить», включение и выключение без перезапуска, предпросмотр на запросе, показы, клики и «В корзину» по каждому правилу.
  - *Сценарии* — готовые примеры для показа.

## Чего нет и почему

- **Сравнения с ценами конкурентов.** Внешних данных о ценах нет, а выдумывать их нельзя.
- **Продуктов 1С.** В фиде их нет, есть только решения для 1С. На «сервер 1С» поиск показывает совместимую СУБД (Postgres Pro для 1С) с пояснением.
- **Настоящей истории поиска.** Журнал покупателей организаторы не передали, поэтому аналитика пока работает на синтетической истории.
- **Нагрузочного теста** с параллельными клиентами в замерах не было.
