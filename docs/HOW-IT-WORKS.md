# Как устроен поиск «Кузницы Softline» — простыми словами

Шпаргалка для команды: откуда поиск знает слова, что в нём заполнено заранее, что считается автоматически и почему для сложных вопросов выбран Jev, а не обычная языковая модель.

## Коротко

Покупатель пишет как привык: «винда хоум», «антивирь», «rfcgthcrbq». Поиск сначала переводит запрос на язык каталога. Это и есть **нормализация**: исправить раскладку и опечатки, заменить жаргон и русское написание бренда на название из каталога. Потом поиск понимает, что нужно: товар, раздел, замена, продление или ответ на вопрос. Затем ищет карточки тремя способами сразу и собирает ответ: минимум четыре товара, нужный вариант лицензии, допродажа, аналоги.

Почти всё работает локально на одном сервере за миллисекунды. Нейросеть Jev подключается только к сложным вопросам и только когда правила сомневаются — примерно в каждом пятом умном запросе.

## Схема

```text
Запрос покупателя: «винда хоум»
   │
   ▼
1. НОРМАЛИЗАЦИЯ — привести запрос к словам каталога
   регистр и «ё» · раскладка · транслит · опечатки · жаргон и русские названия брендов
   «винда хоум» → «microsoft windows» + редакция «home»
   │
   ▼
2. СУЩНОСТИ — что именно названо
   вендор · продукт · раздел · количество · срок · «для дома / для бизнеса» · железо или ПО
   │
   ▼
3. НАМЕРЕНИЕ — что нужно покупателю
   товар · раздел · замена (аналог) · продление · вопрос своими словами
   │   └─ правила сомневаются, включён умный режим → Jev выбирает раздел из списка поиска
   ▼
4. ПОИСК — три способа сразу
   по словам (BM25) · по кусочкам слов (n-граммы) · по смыслу (MiniLM)
   │
   ▼
5. ОТВЕТ
   минимум 4 товара · вариант лицензии под количество и срок · «Вам может пригодиться»
   · «Часто покупают вместе» · «нет в каталоге» с заменами
```

## Что такое нормализация

Нормализация — это перевод запроса покупателя на язык каталога, пока поиск ещё ничего не ищет. Слова в запросе и в каталоге должны совпасть, иначе даже лучший поиск промахнётся.

| Что делает | Пример | На чём работает |
|---|---|---|
| Нижний регистр, «ё» → «е», лишние пробелы | «Винда  Хоум» → «винда хоум» | правила в коде (Python) |
| Раскладка клавиатуры | «rfcg» → «касп» | таблица клавиш ЙЦУКЕН ↔ QWERTY в коде |
| Транслит и звучание | «майкрософт» → Microsoft, «офис» → Office | индекс по звучанию, строится из названий каталога |
| Опечатки | «касперки ендпоинт» → kaspersky endpoint | ближайшее слово из названий каталога, сходство от 85 %, библиотека rapidfuzz |
| Жаргон и сокращения | «винда» → Microsoft Windows, «антивирь» → антивирус | словари базы знаний `kb/` |
| Короткие псевдонимы | «мдаемон» → MDaemon, «каспер» → Kaspersky | таблица в коде |
| Формы слов | «антивирусы» = «антивирус» | морфология pymorphy3 |
| Числа, количество, срок | «на тридцать компов», «на 2 года» | шаблоны (регулярные выражения) в коде |
| Редакция | «хоум» → Home, «про» → Pro | таблица редакций в коде |

Исправление не прячется: в ответе видно и исходный запрос, и как его понял поиск («Понял как: windows home»).

## Откуда поиск знает слова — четыре источника

| Источник | Что внутри | Кто заполняет | Как обновляется |
|---|---|---|---|
| **Каталог магазина (фид)** | 136 040 предложений → 11 713 карточек, 1 232 вендора, 9 311 разделов; цены, наличие, варианты лицензий; словарь слов для опечаток; индекс по звучанию; смысловые векторы | **автоматически** | при каждой загрузке фида, руками ничего не правим |
| **Правила в коде** | раскладка, транслит, числа словами, количество и срок, аудитория («для дома», «для школы»), редакции, короткие псевдонимы | разработчики | вместе с кодом, проверяются автотестами |
| **База знаний `kb/`** | ≈ 2 900 терминов жаргона и написаний, 366 вендоров с вариантами написания, 278 продуктов с аналогами (1 207 замен), задачи своими словами, подсказки «железо или ПО», 238 правил допродажи | **заранее**: черновик писали ИИ-помощники, мы проверяли | записи сверяются с каталогом и прогоняются автотестами (1 137 тестов) |
| **Консоль менеджера** | включить, выключить и изменить правила допродажи; приоритеты направлений и веса выдачи; список «ищут и не находят» — что добавить в словарь | **вручную**, без программиста | сразу из консоли |

Итог: всё, что следует из каталога (опечатки, звучание, формы слов, смысл, цены, варианты лицензий), поиск считает сам. Записывать заранее нужно только то, чего в каталоге нет: жаргон («винда», «антивирь»), старые имена («акронис» → Кибер Бэкап), аналоги ушедших продуктов, задачи своими словами и правила допродажи.

## Сущности: что откуда берётся

| Сущность | Пример | Откуда | Вручную или автоматически |
|---|---|---|---|
| Товар, цена, наличие, раздел | Kaspersky Standard, от 1 129 ₽ | фид | автоматически |
| Вариант лицензии: срок, число мест, тип, продление | «на 30 устройств, продление» | разбор названий предложений фида | автоматически |
| Вендор | «касперский», «майкрософт» | имена из фида + русские написания из `kb/vendors*.yaml` | автоматически + заранее |
| Жаргон и сокращения | «винда», «антивирь», «мелкомягкие» | `kb/slang*.yaml`, `kb/categories.yaml` | заранее (ИИ + проверка) |
| Опечатка | «касперки» | словарь слов каталога | автоматически |
| Неверная раскладка | «rfcgthcrbq» | таблица клавиш | автоматически, правило в коде |
| Количество и срок | «на 20 компьютеров», «на 2 года» | шаблоны в коде | автоматически |
| Аудитория | «для дома», «для школы» | правила в коде + `kb/slang_audience_r3.yaml` | автоматически + заранее |
| Железо или ПО | «сервер» → Rack-серверы, кнопка «Искали ПО для сервера?» | `kb/hardware_hints.yaml` | заранее |
| Аналог, замена | «аналог винды» → Astra Linux, Альт, РЕД ОС | `kb/feed_analogs.yaml` (278 продуктов) | заранее, каждая замена сверена с каталогом |
| Задача своими словами | «чем открыть pdf» | `kb/feed_tasks.yaml`, смысловой поиск MiniLM | заранее + автоматически |
| Сложный вопрос | «как учить сотрудников удалённо» | Jev выбирает раздел из списка | автоматически, только при сомнении |
| Допродажа | Astra Linux → антивирус, резервное копирование | `kb/upsell_r9.yaml` (238 правил) + правки в консоли | заранее + вручную |
| Приоритеты направлений | поднять акционный раздел | консоль | вручную |

**Что будет с новым товаром.** Он появляется в фиде — и сразу попадает в поиск: опечатки, звучание, формы слов и смысл для него считаются автоматически. Если покупатели зовут его жаргоном, этот жаргон появится в консоли в списке «ищут и не находят», и его добавляют в словарь.

## Технологии

- Python 3.12, FastAPI и uvicorn — сервис поиска и API (`/api/search`, `/api/suggest`).
- rapidfuzz — опечатки (сходство слов), pymorphy3 — формы русских слов.
- BM25 и буквенные n-граммы — поиск по словам и кусочкам слов (numpy, scipy).
- MiniLM (`paraphrase-multilingual-MiniLM-L12-v2`) — поиск по смыслу; работает локально на процессоре через onnxruntime, без видеокарты и без внешних вызовов.
- Jev 1.13 (`typesafe/jev-1.13`) через OpenRouter — единственный внешний платный вызов, только в умном режиме.
- SQLite — журнал поисков, кэш решений Jev, данные консоли.
- База знаний — YAML-файлы в папке `kb/`, схема описана в `kb/SCHEMA.md`.

## Почему Jev, а не обычная языковая модель

Обычную языковую модель (чат-модель) просят ответить текстом. Она может придумать товар, которого нет в каталоге, назвать несуществующий раздел или цену. Её ответ приходится разбирать, а уверенности в цифрах она не сообщает. Если звать её на каждый запрос, каждый поиск ждёт модель и за каждый запрос нужно платить.

Jev работает иначе. Это **категоризатор**: он выбирает один вариант из закрытого списка, который составил сам поиск, и возвращает уверенность.

| | Обычная LLM на каждом запросе | Jev |
|---|---|---|
| Что отвечает | свободный текст | номер варианта из списка и уверенность |
| Может придумать товар | да | нет: варианты даёт поиск, в списке всегда есть «подходящего нет» |
| Уверенность | не сообщает | число от 0 до 1; ответ берём от 0,55, иначе решают правила |
| Когда вызывается | на каждый запрос | только в умном режиме и только при сомнении: ≈ 18 % умных запросов |
| Скорость | ответ генерируется по словам | ≈ 0,35 с; дольше 0,6 с поиск не ждёт |
| Стоимость | платим за каждый запрос | ≈ 0,004–0,005 ₽ за вызов, повтор из кэша бесплатно; в среднем ≈ 0,001 ₽ на умный запрос, ≈ 16 ₽ в месяц при 500 поисках в день |
| Если недоступна | поиск ждёт модель | поиск сам отвечает в быстром режиме с пометкой «категоризатор недоступен» |
| Что уходит наружу | зависит от подсказки | только текст запроса и список вариантов, без имён, контактов и реквизитов |

**Настоящий вызов на стенде 27.11.** Запрос «что использовать против вирусов»:
1. Поиск составил список разделов каталога, в конце — «подходящего раздела нет».
2. Jev выбрал «Антивирусы для организаций» с уверенностью 0,9.
3. Вызов занял 0,36 с, 855 токенов, стоил 0,0036 ₽.

Повтор этого же запроса берётся из кэша — 0 ₽.

## Где это в репозитории

- `docs/PIPELINE.md` — подробный путь запроса по шагам, с цифрами.
- `kb/` — база знаний, `kb/SCHEMA.md` — её схема.
- `kuznitsa/text.py` — нормализация и формы слов; `kuznitsa/kb/lexicon.py` — словари.
- `kuznitsa/index/feed.py` — индекс карточек фида и короткие псевдонимы.
- `kuznitsa/llm/jev.py` — вызов Jev; `kuznitsa/config.py` — модель и адрес.
- `docs/UPSELL.md` — правила допродажи.
