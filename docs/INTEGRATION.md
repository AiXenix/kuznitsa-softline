# Поиск Кузницы на сайте партнёра

Поместите строку в тело страницы в том месте, где покупатель выбирает программу. Замените домен адресом своего экземпляра Кузницы.

```html
<script src="https://search.example.org/web/embed/widget.js" data-profile="guest" data-mode="smart"></script>
```

Если магазин и API работают на одном домене, достаточно пути `src="/web/embed/widget.js"`. Скрипт вставляет поиск сразу после себя. Поле, подсказки и карточки живут в Shadow DOM. Стили загружаются с сервера Кузницы. На демонстрационной странице `/embed` можно проверить соседство оформления магазина и поиска.

| Параметр | Значение |
|---|---|
| `data-profile` | Идентификатор демонстрационного профиля из `/api/meta`. По умолчанию `guest`. |
| `data-mode` | `smart` по умолчанию, также доступны `fast` и `naive`. |
| Адрес API | Определяется по origin атрибута `src`. |

Сайт загружает страницу по HTTPS и разрешает в CSP скрипты, стили и соединения с доменом Кузницы. Оператор API указывает точный origin партнёра в `KZ_CORS_ORIGINS`. Разрешение CORS требуется для модулей JavaScript, чтения API и предварительного запроса перед POST JSON. Для голосового поиска нужны поддержка Web Speech и согласие браузера на микрофон. Ключ администратора виджету не требуется.

Виджет создаёт отдельную сессию. Он читает `GET /api/meta`, `GET /api/suggest`, выполняет `POST /api/search` и отправляет `impression`, `suggest_click`, `click`, `exit` в `POST /api/event`. Покупатель может продолжить подбор на полной витрине. Для собственной аналитики сайта при показе результата всплывает событие:

```js
document.addEventListener('kuznitsa:results', event => {
  const {q, search_id} = event.detail;
  // Свяжите поисковую фразу и запись выдачи с событиями своего сайта.
});
```

### Выбор режима

На демонстрационной странице и в магазине партнёра переключатель включается тем же атрибутом.

```html
<script src="/web/embed/widget.js" data-profile="guest" data-mode="fast" data-mode-switch="1"></script>
```

`data-mode` задаёт начальный режим. `data-mode-switch="1"` показывает покупателю «Умный» и «Быстрый». Без этого атрибута виджет использует заданный режим. Смена режима повторяет текущую фразу. Подсказки запрашиваются с выбранным режимом, а ссылка «Продолжить в каталоге» передаёт его вместе с фразой и профилем. Виджет отправляет запрос с источником `widget`; для прежнего API, отклоняющего этот источник, используется совместимый `ui`.

Виджет использует цвета магазина, локальный логотип и оформление товарных плиток. Для подключения разрешите загрузку статики с адреса скрипта и картинок с хостов каталога в политике img-src сайта. Если картинка недоступна, виджет оставляет заглушку. При выборе конкретного товара в подсказках его страница открывается на стороне магазина. Выбор раздела продолжает поиск внутри виджета.
