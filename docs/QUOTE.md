# Спецификация и коммерческое предложение

Закупщик может передать до 200 позиций одним файлом и скачать КП по результату подбора. Для витрины используются два маршрута на том же хосте, что и `/api/search`. Рабочие примеры — [заявка 1С](quote_examples/request-1c.xlsx), [письмо](quote_examples/request.txt), [английская таблица](quote_examples/request.csv) и [200 позиций](quote_examples/order-200.csv).

## Загрузить заявку

```bash
curl --fail-with-body -X POST \
  "$BASE/api/spec/upload?name=request-1c.xlsx&profile_id=smb_trade&mode=fast&session_id=procurement" \
  -H 'Content-Type: application/octet-stream' --data-binary @docs/quote_examples/request-1c.xlsx
```

`BASE` — адрес запущенного стенда. Тело запроса содержит байты файла. Имя файла с пробелами или кириллицей передавайте через `URLSearchParams`. Профиль по умолчанию — `guest`, режим — `fast`. Поддерживаются XLSX, CSV, TSV и TXT размером до 2 МиБ. Текст может быть в UTF-8, UTF-8 с BOM или Windows-1251.

В таблице укажите название, при необходимости добавьте количество, артикул и единицу измерения. Пустое количество означает одну единицу. В письме пишите по одной позиции на строку, например «Kaspersky Small Office Security — 15 ПК». В XLSX над таблицей могут быть реквизиты заявки, внутри — объединённые ячейки. Разбор пропускает строки итогов, пустые названия и некорректные количества. Позиции сверх лимита перечисляются среди пропущенных.

В ответе обычного поиска блок `spec.lines` содержит позиции в исходном порядке. `card` и `total` могут быть пустыми. При наличии артикула он определяет выбранный SKU. Если его нет в каталоге, предложенные замены требуют согласования. Поле `upload` содержит имена распознанных колонок, число разобранных строк после шапки, количество позиций и список `skipped` с номерами исходных строк.

Ошибки возвращают сообщение для пользователя в `error.message`. Код `file_too_large` означает превышение лимита, `file_unsupported` — неизвестное расширение, `file_empty` — пустой файл, `no_positions` — нечитаемую таблицу или отсутствие пригодных строк.

## Скачать КП

```bash
curl -fOJ "$BASE/api/export/$SEARCH_ID?format=xlsx"
curl -fOJ "$BASE/api/export/$SEARCH_ID?format=csv"
```

`SEARCH_ID` берётся из ответа загрузки или обычного поиска. Снимок журнала сохраняет показанный товар и цену. Если в журнале остались только параметры поиска, подбор повторяется для сохранённого запроса и профиля. Для отсутствующего архивного профиля в КП указываются гостевые условия.

В спецификации получается строка на позицию, в комплекте — на слот с числом рабочих мест, в обычной выдаче — до десяти карточек. Для количества и стоимости используются разные колонки. Цена может относиться к пакету, итог учитывает необходимое число пакетов. Для суммы, которую пока нельзя рассчитать, ячейка остаётся пустой. Предварительный итог складывает только рассчитанные строки. На листе «Не найдено» перечислены запросы для уточнения и предложенные замены. CSV использует UTF-8 с BOM и точку с запятой.

Для показа срок действия расчёта принят равным 14 календарным дням от даты поиска. В файле цены обозначены как демонстрационные.
