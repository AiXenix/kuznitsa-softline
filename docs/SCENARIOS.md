# Карта сценариев поиска «Кузница Softline»

Сценариев: 118, групп: 18. Приоритеты: P0 — 67, P1 — 45, P2 — 6.

Сценарий — это вид запроса, по которому поиск ведёт себя по-своему: по-другому понимает запрос, отбирает товары и
строит ответ. Полные описания (как распознаётся, что делает поиск, какие данные нужны) — в `docs/scenarios.yaml`.

Колонка «Намерение» — основной план обработки из закрытого списка: `sku` — артикул или код; `product` — конкретный продукт; `vendor` — производитель; `category` — категория программ; `task` — задача; `role_kit` — комплект для роли или офиса; `industry` — отраслевая подборка; `analog` — замена и аналоги; `compliance` — требования регулятора; `renewal` — продление и докупка; `license_ops` — правила и тип лицензии; `spec_list` — список позиций; `compare` — сравнение; `question` — вопрос; `broad` — слишком общий запрос; `out_of_catalog` — нет в продаже; `off_topic` — не по теме; `account` — мои лицензии и заказы; `service` — услуги; `promo` — акции и пробные версии.
