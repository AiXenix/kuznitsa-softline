# Что внутри: стек, библиотеки, модели и сервисы («Кузница Softline», AiXenix)

Документ содержит перечень сторонних библиотек, моделей, баз данных и сервисов, используемых в решении **«Кузница Softline»** (команда **AiXenix**), с указанием назначения, лицензии и режима работы без интернета. Состав сверен по `requirements.txt`, `pyproject.toml` и `SPEC.md`.

## 2. Ключевые узлы архитектуры отдельно

### 2.1. Локальная модель эмбеддингов
- **Модель:** `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`.
- **Исполнение:** запускается локально на CPU через `fastembed` + `onnxruntime` (без тяжёлого стека PyTorch и без GPU).
- **Автономность:** веса заранее сохраняются в локальный кэш `var/models`, при запуске выставляется `HF_HUB_OFFLINE=1`. После прогрева кэша модель работает полностью без интернета и с нулевой стоимостью за запрос.
- **Роль в поиске:** закрывает семантический слой («задачи своими словами», непрямые формулировки, двуязычные запросы русский/английский) в связке с BM25 и символьными n-граммами.

### 2.2. Категоризатор Jev 1.13 через OpenRouter (единственный внешний платный вызов)
- **Модель и провайдер:** **Jev 1.13** (`typesafe/jev-1.13`) через OpenRouter Decisions API (транспорт — `httpx`).
- **Назначение:** в режиме `smart` используется как быстрый закрытый классификатор намерения/категории и для точного реранка сложных неоднозначных запросов, а также в фоновой разметке сложных кластеров.
- **Экономика и защита бюджета:**
  - Простые и однозначные запросы (артикулы, точные бренды, словарь базы знаний) обслуживаются локальным маршрутом `fast` вообще без обращения к API.
  - Все ответы Jev кэшируются в SQLite (`llm_cache`), поэтому повторные запросы бесплатны.
  - Действует жёсткий суточный лимит расходов (`KZ_LLM_DAILY_BUDGET_USD`).
- **Отказоустойчивость и работа без интернета:** при отсутствии ключа, обрыве сети, таймауте или исчерпании суточного лимита система автоматически и бесшовно деградирует с `smart` на локальный режим `fast`. **Поиск продолжает работать автономно и без Jev**, не ломая выдачу и не возвращая ошибок пользователю.

### 2.3. Хранилище SQLite (WAL)
- Используется встроенная в Python библиотека `sqlite3` в режиме **WAL (Write-Ahead Logging)** — не требует отдельного сервера БД и внешней инфраструктуры.
- Хранит журнал поисковых запросов, события взаимодействия (клики, добавления в корзину, заказы), профили клиентов, кэш ответов LLM, применённые синонимы/правила мерчандайзинга и карточки находок аналитического агента.
- В боевых сценариях с высокой конкурентной записью слой хранилища (`kuznitsa/analytics/store.py`) изолирован и может быть перенесён на PostgreSQL без изменения поискового ядра.

### 2.4. Веб-сервер и интерфейс
- **Бэкенд:** `FastAPI` поверх ASGI-сервера `Uvicorn`. Обработчики поиска синхронные (`def`) и выполняются в пуле потоков, а ядро `Engine.search(request)` не хранит глобального изменяемого состояния.
- **Фронтенд:** чистые статические `HTML / CSS / JS` (`web/`), без бандлеров и внешних CDN — интерфейс открывается и в закрытом контуре без доступа в интернет.
- **Развёртывание:** шаблоны `systemd` и `Caddy` лежат в каталоге `deploy/` для быстрого поднятия сервиса за обратным прокси.

## 3. Что проверить перед сдачей

1. Сверить точные зафиксированные версии пакетов из `.venv` (или `requirements.frozen.txt`) и при необходимости перенести их в колонку «Версия».
2. Убедиться, установлены ли `openpyxl` и `lxml` в `requirements.txt` / `.venv` (в `SPEC.md` они указаны для адаптеров Excel/XML, в текущем `requirements.txt` отсутствуют).
3. Перепроверить актуальные лицензии зависимостей (в т.ч. `fastembed`, `onnxruntime`, `paraphrase-multilingual-MiniLM-L12-v2`) и условия использования `typesafe/jev-1.13` на OpenRouter.
