## Находки

### Поиск

**A. Ложное «нет в каталоге».** Товар в фиде есть, а ответ говорит, что его нет: «ворд», «эксель», «аутлук», «fotoshop», «битрикс 24», «windows 11 pro цена», «windows 11 pro license», «upgrade windows 10 pro», «продление криптопро», «autocad 2025», «цена autocad», «виндоус 11», «Adobe Acrobat Pro», «мс sql». Источник — старая ветка обработки, рассчитанная на учебный каталог: запрос с ценой, сроком, количеством, словами «купить», «цена», «продление» уходит в неё и сверяется не с фидом.

**B. Старая ветка обработки достижима на настоящем фиде.** Она же даёт пустые ответы: «софт для дизайнера», «софт для юриста», «обучение astra linux», «внедрение битрикс24», «курсы excel», «переход с windows на astra linux» — ноль карточек.

**C. Из запроса выбрасываются значимые слова.** «офисный пакет для linux» превращается в «пакет для linux» (акустические расчёты, юридические услуги), «vpn клиент для windows» — в «клиент для windows» (Мегаплан, NTP-клиент), «консультант плюс» — в «плюс», «cad software» — в «software», «жёсткий диск 4 тб» — в «4 тб» (твердотельные накопители), «программное обеспечение для резервного копирования виртуальных машин» ищется по словам «программное обеспечение» (MSDN, «Стройсофт»).

**D. Задача, вопрос и роль попадают не в тот раздел.** «программы для бухгалтера» → резервное копирование; «программы для инженера-конструктора» → Altova (средства разработки); «ищу программу чтобы делать презентации и таблицы» → Visio и Project; «нужно подписывать документы электронной подписью» и «как защитить компанию от вирусов-шифровальщиков» → общий список раздела «Защита информации» без КриптоПро CSP и антивирусов; «докупить лицензии dr.web» → Windows; «импортозамещение exchange» → Postgres Pro.

**E. Главный продукт бренда не первый.** «касперский», «kasperskiy», «продлить лицензию касперского» начинаются с Kaspersky Security для виртуальных сред и систем хранения, а не с Standard, Plus, Premium и Endpoint Security; «dr.web» — без Security Space в первых карточках; «revit» — «Трубопровод Revit» раньше Autodesk Revit; «афтокад» — AutoCAD LT for Macintosh и ModPlus; «corel» — PaintShop раньше CorelDRAW; «компас 3d» — комплекты раньше КОМПАС-3D V25; «криптопро для linux» — КриптоПро Ключ раньше CSP; «windows для организации 50 пк» — Home раньше Pro.

**F. Условия запроса не применяются.** «дешёвый», «самая дешёвая», «недорогой» не сортируют по цене; «бесплатный антивирус» не объясняет, что бесплатных лицензий нет; «для mac», «для windows server», «для android» не влияют на состав; «сапр для astra linux» понимается как «товары производителя Astra» (DCImanager, «Боцман»); «из реестра отечественного ПО» отдаёт Microsoft Visio и Project; «российский сапр» → Altium и WINE@Etersoft; пояснение «В разделе … товаров этого производителя нет» стоит над товарами этого производителя («компас 3d», «астра линукс», «техподдержка касперский»).

**G. Исправление написания.** Не исправляются «касперскй», раскладка «фгещсфв» (autocad), «антивирс для организаци»; исправление портит запрос: «р7» → «h7», «нанок» → «nano»; слитное и раздельное написание дают разный результат («битрикс24» находит, «битрикс 24» — «нет в каталоге»).

**H. Бессмысленный ввод получает случайные товары.** «asdfghjkl», «!!!», «12345», «пицца», «погода в москве» — 0 из 10: вместо просьбы уточнить показываются «Учебные справочники» и «MobiSystems Словари».

Периферия с параметрами.** «ssd 1 тб» → Microsoft SQL Server; «ноутбук 16 гб i7» → жёсткие диски; «сервер dell» → жёсткие диски; «картридж для hp laserjet» → плёнка для ламинирования; «роутер wi-fi 6» и «флешка 64 гб» → «уточните раздел» с VentaFax и Dr.Fone; «мфу лазерное цветное» → плоттер Designjet. Добор до четырёх карточек берёт случайные товары («проектор» → колонки, «графический планшет» → акустика и принтер).

**T. Допродажи повторяются.** Одни и те же карточки «Вам может пригодиться» стоят на каждой странице ответа.

### Подсказки

**J.** Набор подсказок: сдано 59 из 91. Время хорошее (p50 11 мс), но состав повторяет ошибки поиска. Полное слово «антивирус» даёт одну карточку — сертификат на техподдержку; «цшт» (win в русской раскладке) отвечает иначе, чем «win»; «ворд», «эксель», «постгрес» — пусто; число в вводе обнуляет ответ. Ещё примеры: «касп» и «каспер» — без Standard, Plus, Premium; «office» — Office Flexispace и OfficeSuite без Microsoft Office; «авток» — «АвтоКаталог» без AutoCAD; «антив» — только сертификат на техподдержку; «впн», «эцп» — общий список; «нанок» исправляется в «nano» (сетевые карты); «ajnj» → «фото» вместо Photoshop; «кас 10» — пусто.

### Сервис

**K. Чтение админских данных открыто на публичном адресе.** GET `/api/admin/{kpi,rules,queries,priorities,upsell,weights,cost,support,failures}` отвечает 200 без токена — виден журнал запросов и расходы на LLM. Запись закрыта (403). Это режим показа жюри (`KZ_ADMIN_OPEN`); перед открытием адреса кому-либо кроме жюри его нужно выключить.

**L. Ограничение частоты есть и считает по адресу покупателя.** Предел — `KZ_RATE_LIMIT` запросов в минуту на адрес клиента отдельно для поиска и подсказок (на стенде 1200), сверх него ответ 429 с `Retry-After`. Через публичный адрес стенд видит адрес клиента, а не прокси, поэтому посетители не делят один счётчик. Проверочная серия из 80 запросов в 16 потоков предела не достигла — доработка не нужна. Автотеста на предел нет.

**M. Заголовки безопасности.** Есть `referrer-policy` и `x-content-type-options`; нет `Content-Security-Policy`, `X-Frame-Options`, `Strict-Transport-Security`.

Проверено и в порядке: запрос в 20 000 символов отклоняется (422) без задержки; пустые `/api/event` и `/api/spec/upload` — 422; в `web/js` нет вставки разметки через `innerHTML`; `/health` отвечает, `robots.txt` закрывает индексацию.

**U. Нагрузка.** Один процесс движка в быстром режиме отдаёт около 50 запросов в секунду на 10 ядрах; дальше растёт очередь, ошибок нет. Для витрины с большим потоком нужны несколько процессов за балансировщиком, каждый занимает около 3 ГБ памяти.

### Что нашлось при сведении потоков

Потоки работали независимо, поэтому часть ошибок проявилась только после слияния. Каждая исправлена и закрыта тестом.

- «продление криптопро» отвечало как обычный товар: ветка продления не выставляла вид запроса.
- Запрос о переходе («миграция с microsoft office на р7») получал лишнее исправление написания: разговорные названия разбирались раньше цели перехода.
- «3д макс» показывал первым AutoCAD: название линейки принималось за вендора, и вперёд выходили остальные главные продукты Autodesk.
- Полное название с повтором слова («ИБП Powercom WOW WOW-300») теряло повтор при очистке ввода и переставало совпадать с карточкой.
- На точное название карточки числа из названия становились условиями отбора: ответ сужался до одной карточки без соседей и допродажи.
- Запросы с характеристиками («кабель hdmi 2 м», «роутер wi-fi 6») попадали и под ослабление запроса, и под разбор параметров. Теперь отвечает разбор параметров.
- В выдаче класса первая плитка допродажи встаёт не раньше четвёртого места: порядок класса и политика допродажи сведены в одно правило.
