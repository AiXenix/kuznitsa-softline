## Зачем

Пользователь проверил стенд сам. «Каспер для хоума» → «Поиск по вендору Kaspersky», слова «для хоума» потеряны. «Касперский для дома» → пустая выдача. Умный режим ведёт себя так же, как быстрый: категоризатор об остатке запроса никто не спрашивает. «Как будто он не особо умный». Это главное в ходе.

## Задачи

**P0**

1. **Шаг `refine` (29.2).** Второй вопрос категоризатору — `audience` и `line` в одном вызове Decisions:
   - когда спрашивать: условия 29.2;
   - кандидаты `line` — до 8 продаваемых линеек найденного вендора или раздела с подписью «для кого» (Neon‑4 добавит подписи; пока бери описание линейки);
   - порог 0,55, кэш, предел 600 мс;
   - в ответе — `understood.refined`, метка «Понято: …», трасса.

   Быстрый режим — тот же результат по словарю аудиторий и платформ, без вызова. Neon‑4 добавит слова в базу знаний, а базовый набор (хоум, домик, домашний, для дома, маме, ребёнку, личный, сервер, андроид, айфон, мак, линукс, ноут, телефон) заведи сам в своей зоне, если его нет.
2. **Пустой выдачи на понятный запрос не бывает (29.3):** честная строка + ближайшие продаваемые варианты + ссылка на FAQ. Обязательные случаи:
   - «касперский для дома»;
   - «антивирус для дома на 3 устройства»;
   - «windows home для офиса»;
   - запрос с линейкой ушедшего вендора.
3. **Система, а не вендор (29.4):** «резервное копирование 1с», «бэкап постгреса», «мониторинг exchange», «антивирус для 1с сервера».
4. **Слабые виды E2** — общие правки, а не под фразы:
   - строки спецификации с операцией (образовательная, миграция, для госучреждений) и единицей (место, узел, устройство);
   - жаргон из `attrs.aliases` и база знаний;
   - «отечественная замена X на N узлов» — это `analog`, а не комплект;
   - честное «нет в каталоге» при слабом лексическом совпадении. Pinnacle Studio ≠ Studio One, PassMark ≠ Пассворк: если совпала одна общая часть слова или только вендорский префикс, это не совпадение;
   - транслит и раскладка составных названий через дефис;
   - опечатка в первых буквах.
5. **Хвосты хода 5:**
   - ОКВЭД вместе со словами «реестр» и «стек лицензий» → `industry` с условием реестра, а не `compliance`;
   - INS‑14 потока B: запрос о миграции на российское ПО возвращает только Windows Server, подробности — `REPORT-B4.md` в копии `analytics`;
   - «резервное копирование 1с» — см. пункт 3.
