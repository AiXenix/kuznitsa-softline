   - на «каспер для хоума» показывается «нет в продаже — KSOS» вместо домашнего Kaspersky.

   Верни `catalog: yes`. `upgrade_to` и бизнес-`analogs` оставь для другого случая: домашнюю линейку ищет организация (профиль не гость или `audience` = `business`). Тогда в ответе строка про лицензионное соглашение (EULA) и бизнес-замена. После пересборки демокаталога (это D, сборка — моя) проверь:
   - «каспер для хоума», «касперский для домика», «антивирус для дома на 3 устройства» → домашние линейки первыми, метка «Понято: для дома»;
   - dev‑0027 проходит.
2. **Пустая выдача на понятный запрос.** На закрытом наборе пусто в пяти случаях. Закономерности (тесты пиши своими формулировками):
   - разговорные слова класса: «антивирь», «от вирусов», «защита телефонов», «резервная копия <системы>»;
   - платформа macOS — если товаров под неё нет, покажи кроссплатформенные и честно скажи;
   - «маленькая контора» → `micro_office`;
   - «файлопомойка», «файловый сервер» → `server`.
3. **Хвосты отложенной выборки** — общие закономерности, тесты своими формулировками:
   - «переход с X на Y на N мест», «клиентские / сетевые / плавающие лицензии» → `license_ops`;
   - продление продукта ушедшего вендора → `analog` с заменами, а не `renewal` или `out_of_catalog`;
   - «в чём открывать файлы <формат>» → замена по формату;
   - «курсы / обучение / внедрение X» → `service` с вендором X, а не комплект;
   - «нужен ли сертификат … компании», «можно ли» → `answer`, а не комплект;
   - «показать купленные лицензии моей компании» → `account`;
   - «упал контроллер домена, нужна лицензия ALD Pro» → `product` ALD Pro, а не замена;
   - склеенные слова с количеством: «касперантивируспродление30пк»;
   - метрика «на 4 физических процессора»;
   - «кп на 3 аналога X» → блок аналогов, а не сам X.
