## Задачи

**P0**

1. **Витрина как store.softline.ru** (30.7).
   - Шапка: логотип, «Каталог», строка поиска с красной кнопкой, ссылки «Сравнение / Войти / Избранное / Корзина», меню разделов.
   - Карточки: картинка из `picture` с заглушкой, если её нет; вендор; название; условия лицензии; цена или «Цена по запросу»; «Акция −N %» со старой ценой; «Под заказ»; «В корзину».
   - Покупатель видит просто магазин.
2. **Шестерёнка** в правом верхнем углу открывает боковую панель:
   - режим (умный, быстрый, обычный) и профиль клиента;
   - «Понято так», трасса, сравнение режимов;
   - сценарии и режим показа;
   - ссылки на `/flows`, `/docs`, `/admin`.

   Всё прежнее для жюри доступно, но спрятано. Режим показа `/?show=1` открывает панель сам.
3. **Быстрый поиск** (30.6) — выпадающее окно под строкой с двух символов. Группы: «Возможно, вы искали», «Запросы», «Товары» (до 4, с картинкой и ценой), «Разделы», «Возможно, вам понадобится» (до 2). Работают клавиатура и мышь, телефон 390 px.
4. **Допродажи в ленте** (30.5): плитки `kind: "upsell"` с меткой «Вам может пригодиться» и причиной мелким шрифтом, плюс блок «Часто покупают вместе». Добранные карточки (`fill`) — с подписью «Похожие товары». Метка «Искали ПО для сервера?» — кнопкой.
5. **Консоль, раздел «Допродажи».** Таблица правил «ищут → предлагаем → причина → вес → вкл.», редактор, предпросмотр на запросе, счётчики. API делает B; до слияния — заглушка по 30.5.
