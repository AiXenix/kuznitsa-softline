## Задачи

**P0**

1. **Быстрый поиск на демонстрационной странице (28.6)** — просьба пользователя. Сейчас виджет на `/embed` всегда ищет в умном режиме, выбора нет.
   - Переключатель «Умный / Быстрый»: атрибут `data-mode` задаёт режим, `data-mode-switch` показывает переключатель.
   - Подсказки и выдача работают в обоих режимах.
   - «Продолжить в каталоге» передаёт режим.
   - На витрине и в режиме показа переключатель работает так же.
   - Тест и снимки обоих режимов.
2. **«Настройки → Приоритеты направлений» (28.3).**
   - Таблица правил, редактор, предпросмотр «было / стало», журнал изменений.
   - API делает B; до слияния в тестах — заглушка по контракту 28.3.
   - Подписи — из `labels` в `/api/meta`; `criteria` и `tags` туда добавит A.
3. **Страница `/flows` «Как работает поиск» (28.4).**
   - Данные: схемы — из `docs/flows/flows.json`, время — из `timings.json`, примеры — из `examples.json`. Эти файлы делает F по формату 28.4; пока их нет — работай на своём образце в `web/fixtures/flows*.json`.
   - Схемы рисуй своей отрисовкой в SVG или локальной копией Mermaid (лицензия MIT, без CDN).
   - Печать в PDF — через стиль печати.
   - Ссылки на страницу — из «О решении» и из режима показа.
4. **Кнопка «Повторить» на карточке** с `card.action` (`type="repeat_order"`, `order_id`, `label="Повторить"`).
5. **Сквозная проверка на копии данных стенда** (сборка с `main`), со снимками:
