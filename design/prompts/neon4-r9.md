# Кузница Softline · Neon‑4 · ход 9: допродажи и словарь для настоящего каталога store.softline.ru

Хакатон начался, организаторы выдали настоящий каталог store.softline.ru. Сначала прочитай `design/spec-v1.0.md` (30.1, 30.2, 30.5). Терминалом не пользуйся.

Дерево разделов фида — `design/proposals/neon4/real-categories.tsv`. Колонки: уровень, id, родитель, путь, число предложений, главные линейки.

**Зона:** `kb/upsell_r9.yaml` (новый), `kb/slang_r9.yaml` (новый), `design/proposals/neon4/**`.

## Задачи

1. **`kb/upsell_r9.yaml` — не меньше 150 правил допродаж** в формате 30.5. В `when` и `offer` — id классов (уровень 2) или линеек (уровень 3) фида, вендоры — как в фиде.
   - Охват: офисные пакеты, ОС (Astra Linux, РЕД ОС, Windows), серверное ПО, СУБД, виртуализация, 1С и учёт, САПР, графика, антивирусы и защита информации, резервное копирование, удалённый доступ, ВКС и МТС Линк, электронная подпись и КриптоПро, оборудование (серверы, ноутбуки, рабочие станции, сетевое, периферия) и ПО к нему.
   - Примеры:
     - офис → антивирус, резервное копирование, PDF-редактор;
     - Astra Linux → ALD Pro, защита для Linux, RuBackup, Secret Net LSP;
     - Windows Server → клиентские лицензии (CAL), серверный антивирус, резервное копирование;
     - 1С → КриптоПро и ЭЦП, отчётность, резервное копирование;
     - САПР → просмотрщики, PDM, мощная рабочая станция;
     - ноутбук → антивирус, офис, сумка или мышь;
     - сервер (железо) → ОС, виртуализация, резервное копирование, ИБП.
   - У каждого правила — короткая причина для покупателя («К офису обычно берут антивирус») и `source`: `kb` или `vendor_site:<url страницы вендора>`, где связь подтверждена (совместимость, «работает с …»).
   - Только связи, в которых уверен.
2. **`kb/slang_r9.yaml` — жаргон и опечатки под этот каталог.**
   - Примеры: «антивирь», «офис», «винда», «вин сервер», «астра», «астра линукс», «мдаемон» → MDaemon, «мтс» → МТС Линк, «365» → Microsoft 365, «макс патрол» → MaxPatrol, «сканер вс» → Сканер-ВС, «крипта» и «крипто про» → КриптоПро, «касп» и «каспер» → Kaspersky, «драйвер» и «дрвеб» → Dr.Web, «1эс» → 1С, «автокад», «компас», «нанокад», «эксель», «ворд».
   - Только то, что подтверждается названиями в фиде или сайтами и форумами вендоров. Формат — как `kb/slang*.yaml`.
3. **Подписи «Искали ПО для …?»** — для классов оборудования (сервер, ноутбук, коммутатор, моноблок, монитор, принтер, ИБП) с указанием, какой класс ПО предлагать. Это отдельный раздел в `upsell_r9.yaml` или отдельный файл в твоей зоне — опиши формат в заметках для A.

Заметки — `design/proposals/neon4/NOTES-r9.md`. Порты и службы не поднимай, `git commit` не делай. По завершении — короткий итог.
