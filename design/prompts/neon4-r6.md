## Зачем

Пользователь написал на стенде «каспер для хоума» и «касперский для домика». Поиск понял только вендора: слова о том, для кого покупка, база знаний не знает. Ещё хуже «касперский для дома»: домашних лицензий в каталоге нет, и выдача получается пустой.

## Задачи

**Зона:** `kb/*_r3.yaml`, `kb/families/*_r3.yaml`, `design/proposals/neon4/**`.

1. **Словарь аудиторий и платформ.** Значения `audience` — по закрытому списку 29.2: `home`, `micro_office`, `business`, `enterprise`, `gov`, `edu`, `server`, `mobile`, `industrial`. Платформы — сервер, Windows, Linux, macOS, Android, iOS. Формат — по образцу `kb/slang*.yaml`; если подходящего поля нет, опиши формат в заметках для A. Для каждой аудитории и платформы — разговорные формы, жаргон и падежи, например:
   - хоум, домик, домашний, для дома, для семьи;
   - маме, папе, ребёнку, бабушке, себе, личный;
   - на ноут, на телефон, андроид, айфон, мак, линукс;
   - для серверов, на сервер, для 1с-сервера.
2. **«Для кого» у линеек.** У каждой продаваемой линейки популярных вендоров (Kaspersky, Dr.Web, ESET, PRO32, Microsoft, 1С, Астра, РЕД ОС, МойОфис, Р7, Кибер Бэкап, RuBackup) — короткая подпись: для кого линейка и на сколько мест. Например:
   - «KES для бизнеса — компании от 5 рабочих мест, есть серверная защита»;
   - «KSOS — малый офис, 5–25 устройств, без сервера администрирования».

   По этой подписи категоризатор выбирает линейку. Для линеек, которых нет в продаже (домашние), укажи `analogs` — ближайшую продаваемую бизнес-линейку того же вендора.
3. **«Система, а не вендор» (29.4).** Связи совместимости: какие продукты резервного копирования, мониторинга и защиты работают с 1С, PostgreSQL, Exchange, MS SQL, Astra Linux. Только то, в чём уверен; сомнительное — в заметки.
4. **Публичный набор `design/proposals/neon4/probes-audience-r6.jsonl`, 80 строк** (29.8). Поля: `q`, `expect` — `{"audience"?, "platform"?, "vendor"?, "line"? или "category"?, "not_sold"?: true}`, `note`.
   - Состав: по 10 на аудитории, платформы и жаргон аудиторий; 15 на «нет в продаже, нужен ближайший»; 15 на «система, а не вендор»; 10 смешанных.
   - Ожидания — только из базы знаний и каталога, без догадок.

Заметки — `design/proposals/neon4/NOTES-r6.md`, там же просьбы к A.
