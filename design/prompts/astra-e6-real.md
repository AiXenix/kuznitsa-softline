## Что нужно

`hidden/truth-queries.jsonl` — 400 запросов, какие писал бы покупатель store.softline.ru. Ожидания строятся только из фида, правила — в `hidden/RULES.md`.

Поля:

- `q`, `kind`, `note`;
- `expect_groups` — список `group_id`; успех — любой из них в первых пяти карточках;
- `expect_categories` — id разделов, для запросов «класс»;
- `expect_domain` — `hardware` / `software` для неоднозначных;
- `expect_absent` — для отсутствующих.

Виды — примерно поровну:

- название продукта;
- артикул (`vendorCode`);
- опечатка, раскладка, транслит;
- жаргон («антивирь», «винда», «офис», «астра»);
- класс;
- класс + вендор;
- класс + количество (по «К-во пользователей до» и «К-во узлов»);
- продление;
- задача своими словами;
- вопрос («что использовать против …»);
- **«железо или ПО»** — голое «сервер», «ноутбук», «коммутатор» и «ПО для сервера», «лицензия windows server»;
- отсутствующий продукт;
- запросы из 10 примеров организаторов в других формулировках.

Плюс `hidden/upsell-checks.jsonl` — 50 запросов, где у правильной выдачи должен быть хотя бы один уместный сопутствующий раздел. Список допустимых классов к каждому запросу — по здравому смыслу и сайтам вендоров, с источником в `note`.
