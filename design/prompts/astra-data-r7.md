## Задачи

**P0**

1. **Имена атрибутов → стандартные ключи.** Атрибуты МойСклад (`attributes[].name`) и характеристики 1С («Ключ: значение») сопоставляются по смыслу, без учёта регистра, ё/е и пунктуации. Словарь синонимов имён держи в одном месте, `kuznitsa/ingest/` — им пользуются все форматы.

   | Имя в каталоге | Ключ |
   |---|---|
   | «Замещает», «Аналог для», «Альтернатива», «Вместо» | `attrs.analog_of` |
   | «Также ищут», «Жаргон», «Синонимы», «Теги поиска», «Ключевые слова» | `attrs.aliases` |
   | «Назначение», «Задача», «Решаемая задача», «Для чего» | `attrs.task` |
   | «Редакция», «Исполнение», «Версия продукта» | `attrs.edition` |
   | «Операция», «Вид лицензии», «Тип лицензии», «Вид поставки» | `attrs.operation` |
   | «Страна», «Страна разработки», «Производство» | `attrs.country` |
   | «Номер в реестре», «Реестр Минцифры» | `attrs.registry_no` |

2. **Виды цен → нормализованные ключи** `attrs.prices`: `retail` (розничная), `project` (проектная), `partner` (партнёрская), `gov` (для госзаказчиков), `wholesale` (оптовая). Исходные имена тоже сохраняются. В `DAYX.md` — таблица соответствия.
3. **Отчёт дня:** сколько атрибутов сопоставлено с каждым ключом и какие имена остались несопоставленными — полезно ведущему в день X.
