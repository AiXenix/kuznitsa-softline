## Зачем

закупщик юрлица: прислал спецификацию файлом — получил коммерческое предложение файлом.

1. **Образцы артикулов — в git.** `kuznitsa/mock/catalog_gen.py` берёт настоящие артикулы из каталога `design/ref/softline`,
   которого нет в репозитории (в твою копию он положен только для этой задачи; в git он не попадает — закрыт `.gitignore`).
   Перенеси нужное в `kuznitsa/mock/sample_codes.tsv`: только артикулы производителей и штрихкоды с привязкой (семейство,
   редакция, условия) — без текстов и цен магазина. Добавь штрихкод `4601546092816` коробочному продукту 1С: по нему ищет
   строка dev‑0069 (какой товар она ждёт — см. `eval/queries.dev.jsonl`, только чтение). Сборка каталога больше не читает
   `design/ref`. Каталог не должен обеднеть: `KL4867RAQFR` и `FQC-10572` на месте, число предложений и карточек прежнее.
2. **Спецификация из файла** — 27.5: `POST /api/spec/upload`. Движок и журнал — как в `kuznitsa/api/admin.py`
   (`request.app.state.engine`). Разбор: строка заголовков находится сама (в выгрузках 1С над таблицей бывает шапка);
   колонки названия, количества, артикула и единицы — по названиям и по содержимому; объединённые ячейки, пустые строки,
   строка «Итого». Образцы в `docs/quote_examples/`: заявка из 1С (XLSX с шапкой), список из письма (TXT), таблица
   с английскими заголовками (CSV), файл на 200 строк.
3. **Коммерческое предложение** — 27.5: `GET /api/export/{search_id}`. Ответ поиска бери из журнала; если журнал хранит
   не всё нужное — повтори поиск по сохранённому запросу с тем же профилем. XLSX — `openpyxl`: ширины колонок, формат
   денег, закреплённая шапка, итог формулой; файл открывается в Excel и LibreOffice без предупреждений.
4. **День данных одной командой.** `python -m kuznitsa.ingest.cli day <папка> [--ai off|embed|jev] [--ai-budget-usd …]`:
   сама находит в папке каталог, историю запросов и выгрузку Метрики (по содержимому, не по имени); импортирует каталог;
   строит индекс; импортирует историю (функции потока B в `kuznitsa/ingest/history.py` — только вызывай; B в этом ходе
   учит их незнакомым формам); делает повторный прогон и предложения агента; пишет `day_report.json` и `day_report.md`:
   что за что принято, сколько строк взято и отброшено, **покрытие базой знаний** (доля предложений с распознанными
   вендором, классом и семейством; первые 50 нераспознанных вендоров и классов по числу предложений; слова из запросов
   истории, которых нет ни в каталоге, ни в словаре), самопроверка поиска (`selfcheck`). Всё — в новый каталог данных;
   действующий не трогается. Отрепетируй на трёх заведомо чужих наборах (прайс 1С с шапкой и объединёнными ячейками;
   YML‑выгрузка; CSV с английскими заголовками и ценами в долларах); наборы — в `docs/ingest_examples/day_*/`.
