## Задачи

**P0**

1. **Режим показа `/?show=1` — финальный маршрут.** Сверь шаги с `docs/DEMO.md` из `main` и дополни, чтобы вся история показывалась кнопками, без набора с клавиатуры:
   - «каспер для хоума» в быстром и умном режимах: метка «Понято: для дома», шаг `refine` в трассе;
   - честный ответ «нет в продаже» с заменами;
   - «резервное копирование 1с»;
   - сцена приоритетов: включение примера → предпросмотр → витрина `gov_clinic` и гость → выключение;
   - `/flows` и `/docs`.

   Каждый шаг проверь на копии данных стенда с кодом `main`. Шаги, где ответ движка расходится с текстом, перечисли в отчёте для A и ведущего.
2. **`/docs` на всех документах.** Проверь, что каждый документ из `docs/*.md` открывается и печатается без ошибок, включая `README-ИТОГ.md` и `DAYX.md`. Отдельно — таблицы на телефоне 390 px.
3. **Снимки для итогового отчёта:** 8–10 лучших кадров в `design/proposals/ui/final-screens/` — витрина, понимание запроса, трасса, `/flows`, `/docs`, консоль руководителя, агент, приоритеты, виджет в быстром режиме, загрузка спецификации и КП. И `gallery.json` по формату плагина: `{"title", "images": [{"file", "label"}]}`, пути — относительно этой папки.
