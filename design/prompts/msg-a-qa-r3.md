# Дополнение к M2b — наблюдения с живого стенда

Это не новый ход: включи пункты в текущую работу M2b. Я прошёл стенд (выпуск `21b0312`) глазами жюри; ниже только то,
чего нет в задании M2b или что его уточняет.

1. **Заявка вместо товаров при распознанном семействе.** «астра линукс для школы 40 мест» (гость, умный режим): семейство
   распознано, а ответ — «Подходящих предложений по заданным условиям нет» и заявка. Ожидается: карточки Astra Linux
   с лицензиями для образования; если точной ступени или аудитории нет — ближайшие варианты с объяснением и `relax_hints`.
   При этом умный режим не сделал ни одного вызова: шаг категоризатора «Пропущен», 4 мс. Правило: в умном режиме пустая
   товарная выдача или низкая уверенность быстрого пути — повод спросить категоризатор, а не пропустить его.
2. **Цена при ответах из кэша.** Новое необязательное поле `cost.saved_rub`: сколько стоили бы ответы, взятые из кэша
   (сумма исходной цены этих ответов в рублях; `null`, если цена не сохранена). Витрина покажет «0 ₽ · без кэша ≈ 0,01 ₽».
   У шагов трассы с моделью — цена в рублях рядом с долларами.
3. **Подсказки.** Сейчас для «касп»: KESB, Kaspersky MSA, Kaspersky ASAP, «Kaspersky» (это `kaspersky_standard_home` под
   именем вендора), KSOS; затем вендор. Нужно: порядок по популярности с учётом сегмента профиля (юрлицу — сначала
   корпоративные продукты, домашние ниже), различимые названия и новые группы той же формы
   `groups: [{type, title, items: [{text, kind, meta}]}]`: `corrections` (раскладка и опечатки), `queries` (продолжения
   запроса из популярных фраз: «антивирус для бизнеса», «антивирус на 30 пк»), `categories`, `licenses` (лицензии профиля,
   подходящие под начало ввода: «Продлить … — истекает через 24 дня»). У элемента — необязательные `hint` (серая подпись)
   и `q` (запрос по клику, если он отличается от `text`). Поток C отрисует любые группы по их `title`.
4. **Метки «Понято так».** По запросу «комплект бухгалтера на 5 человек» метки собраны из сырых слов: «комплект
   бухгалтера ×», «5 ×». Метка — распознанная сущность с подписью: «Роль: бухгалтер», «5 рабочих мест».
5. **Гость.** `/api/profile/guest` отдаёт `segment: "smb"`, и витрина подписывает анонимного посетителя «Малый бизнес».
   Для гостя `profile.segment_title` = «Гость», вес персонализации не применяется.
6. **Название режима `naive`.** Всюду, где движок отдаёт подписи режимов (`/api/meta`, трасса, заметки): «Обычный поиск
   по словам». Мы не утверждаем, что воспроизводим настоящий поиск магазина, — это модель типового поиска по совпадению слов.

Каждый пункт — с тестом; в `REPORT-M2b.md` отметь их отдельным разделом.
