Умный режим на чужих каталогах ничего не добавляет: категоризатора не спрашивают, к какому разделу чужого дерева относится запрос. Это идея пользователя: «пусть Jev понимает, к какой категории всё-таки относится».

## P0 — общие закономерности (тесты своими формулировками)

1. **Категоризатор для чужого дерева (умный режим).** Быстрый путь дал `unknown_term`, `off_topic` или «нет в каталоге», а запрос похож на просьбу: задача, английская фраза, система, жаргон, «чем заменить X». Тогда:
   - выбери до 8 разделов загруженного дерева по плотному сходству запроса с названиями разделов, названиями и описаниями товаров. Модель MiniLM многоязычная и сравнивает английский запрос с русскими названиями;
   - спроси Jev закрытым списком: «какой раздел нужен покупателю» плюс `none`, порог 0,55, кэш, предел 600 мс;
   - покажи этот раздел с пояснением «Понято: <раздел> (умный режим)».

   Быстрый режим без вызова: тот же отбор кандидатов по сходству. Если первый кандидат уверенно лучше второго — показываем его с пометкой «похоже, вы ищете». Иначе — `clarify` с 2–3 разделами.

   Формы запросов, которые сейчас уходят в постороннее:
   - «уменьшить отходы при раскрое», «подготовить межевой план», «составить монтажную ведомость», «склеить панораму помещения», «распределить посетителей по окнам», «принимать заказы у столика»;
   - «industrial SCADA software», «subtitling software», «digital signage players», «shift planning software»;
   - «админка сайтов linux», «синхронизация баз postgres», «архив почты exchange».
2. **«Чем заменить / российская альтернатива для X»**, где X не знают ни каталог, ни база знаний (FlexiCapture, WinCC, Autodesk Vault, Kissflow). Определи раздел X тем же способом — по сходству и вопросом Jev — и покажи отечественные товары этого раздела. Если в каталоге есть `attrs.analog_of`, он главнее.
3. **Исправления на названиях загруженного каталога.** Сейчас «bcad vt,tkm», «ujccnhjqcvtnf», «огсстройсмета», «archivem anager», «sieblius artist» уходят в постороннее. Словарь раскладки, транслита и опечаток должен строиться и из серий, названий и вендоров загруженного снимка, а не только из нашей базы знаний. Проверь, что он пересобирается при `Engine.open` на снимке `day`.
4. **Вопрос о продлении:** «Какие данные нужны, чтобы продлить «X»?», «что нужно для продления X» → `answer` с порядком действий и карточки X.
5. **Продление другими словами:** «X — ещё один год по действующей подписке» → `renewal`. Сейчас уходит в `industry`.
6. **Бюджет по виду цены:** «в розницу до …», «по проектной цене до …», «для партнёра до …», «для госзаказчика до …». Бери `attrs.prices` по виду цены — ключи нормализует D. Если вида цены нет, бери розничную и скажи об этом.
7. **«Нет, но похоже» с версией:** «SprutCAM 7», «ГРАНД-Смета 7», «iSpring Suite 7», «NetSupport School 10», когда продаётся текущая версия без номера. Ответ — «версии 7 нет, продаётся …» и карточка с этой пометкой, а не молчаливое совпадение.
8. **Спецификация на чужом каталоге:** «Swift Publisher; Базовая; Новая лицензия; партия 2 места». Сопоставляй редакцию и операцию с `attrs.edition` / `attrs.operation` предложения: ключи нормализует D.
9. **Аудитория с разделом на чужом каталоге:** «электронные заметки маме», «панорамная съёмка для дома». Раздел известен, значит «нет в каталоге» недопустимо. Если домашних редакций нет — раздел с пометкой.

## Приёмка

- свои тесты по каждому пункту;
- на своём независимом прайсе (как в M2f) — таблица «было / стало»;
- dev ≥ 304 в обоих режимах, знакомые комплекты 125/125, ОКВЭД 30/30;
- smart не хуже fast, fast p95 ≤ 40 мс, smart p95 ≤ 700 мс, умный запрос ≤ 0,03 ₽;
- `pytest` зелёный.

Это последний ход движка перед заморозкой: никаких рискованных переделок — только общие правки с тестами.
