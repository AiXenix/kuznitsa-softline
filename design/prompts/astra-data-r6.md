## Задачи

**P0**

1. **Excel из 1С:УТ «Номенклатура».**
   - Иерархия групп задаётся одним из трёх способов: уровнями группировки Excel (outline level строк), отступом в ячейке наименования или колонкой «Родитель». Группы — это путь категории, а не товары.
   - Характеристики собраны в одной ячейке через «;» вида «Ключ: значение» → `attrs`: вендор, серия, редакция, срок, единица, количество, страна, реестр.
   - Строки групп и итогов не считаются товарами.
2. **«Цены номенклатуры»** — несколько видов цен в колонках («Розничная», «Оптовая», «Для госзаказчиков» и т. п.).
   - Основная цена — розничная.
   - Остальные виды сохраняются в `attrs.prices` по имени вида цены.
   - Связь с номенклатурой — по коду или артикулу.

   В `DAYX.md` опиши, как назначить вид цены сегменту (госзаказчик → «Для госзаказчиков»). Применять это будет A.
3. **История в нестандартных файлах.** Маршрутизация через `history.sniff`: B добавит виды `metrika_api` и `support_chat`.
   - Ответы API отчётов Метрики (`/stat/v1/data`, JSON с `query`, `data[].dimensions`, `metrics`, `totals`) — несколько файлов одного отчёта по страницам.
   - CSV обращений покупателей из чата поддержки.

   Сейчас каждый JSON засчитывается как одна строка истории, а чат не распознан.
