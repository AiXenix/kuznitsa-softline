# M3e · переформулировки и подбор в разделе

Проверка на `real/v1` — 136 040 предложений, 11 713 карточек. Успех для переформулировки означает, что поиск распознал продукт и первая основная карточка принадлежит ожидаемой линейке. Для семейства с явно указанной редакцией тест проверяет её карточку. Для Кибер Бэкап и МТС Линк без указания редакции допустимы продаваемые редакции этой линейки.

## Переформулировки

Одни и те же 60 открытых формулировок (по шесть на продукт) на `1cc6eed` давали верную первую карточку в 29 случаях в fast. В четырёх из них намерением был раздел. По более строгой проверке «первая карточка плюс намерение product» исходный результат — 25/60. Добавлена отдельная проверка короткого запроса «Office 2024 года», всего 61 формулировка. Процент на закрытом наборе ведущего измеряется отдельно.

Поиск проверяет название после слова класса по продаваемым линейкам, произношениям и алиасам. Версия словами, порядковый номер, префикс `v` и год выпуска приводятся к записи каталога. Например, «CSP пятой версии» находит КриптоПро CSP 5.0. Уточнение назначения сохраняет явно названную редакцию, включая Family. Для выпуска без указанной аудитории у бизнес-клиента есть предпочтение деловой редакции, у образовательного клиента — учебной. Основание для этого выбора в запросе «Office 2024 года» — в каталоге продаются обе редакции.

## Раздел, тираж и вендор

«Серверное ПО», «Системы автоматизации» и «Программы для машиностроения» — самостоятельные разделы второго уровня реального дерева (369, 2942 и 8842). В них соответственно 181, 311 и 65 карточек. Тираж определяет вариант поставки внутри карточки. Базовые линейки предшествуют агентам, клиентам и дополнениям. Во всех предложениях этих трёх разделов в снимке популярность равна 0,5. При равном значении поиск учитывает наличие и количество вариантов поставки. При отсутствии подтверждения тиража карточка получает отметку «Тираж требует уточнения». При повторе с количеством 3, 73 и 420 каждый из трёх разделов сохранил полный состав. У КОМПАС-3D и ThinLinc в расчёт попали все три тиража. У первого серверного предложения цена по запросу, рублёвой суммы нет.

| ПО для видеонаблюдения на сервер | Раздел ПО для видеонаблюдения, CVS-IP с указанием сервера в предложении |

Вендор определяется также по однозначному краткому имени издателя из фида. Для соседних товаров вендора учитываются домен, ветка дерева и сходство названий и описаний. Для серверного назначения используются метрика лицензии и название варианта поставщика. Если в разделе нет подтверждённого серверного предложения, поиск показывает раздел и предлагает уточнить совместимость.

## Воспроизведение

Набор формулировок находится в `tests/fixtures/m3e_phrasings.json`. Команда `.venv/bin/python -m pytest -q tests/test_m3e.py` проверяет оба режима без сети. При `KZ_TEST_REAL_FEED=/home/bb/kuznitsa-softline-ops/real/v1` тесты переформулировок читают полный снимок и используют отдельный временный журнал. Для официальной десятки используется `scripts/check_real_feed.py <рабочая копия снимка> --mode both`.
