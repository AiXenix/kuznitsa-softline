# M3h · аналоги и близкие товары

На снимке `real/v1` проверен поиск с тестовым фрагментом справочника из шести записей. Полный `kb/feed_analogs.yaml` ведёт редактор. После слияния он загрузится при открытии снимка. Продуктовых названий из фрагмента в правилах движка нет.

| Запрос | Первые замены на снимке |
|---|---|
| Luminar Neo | ФотоМАСТЕР, затем другие программы для обработки фото |
| Reason 13 | Ableton Live 10, SONAR X2 Studio |
| Total Commander | File Commander, Eltima Commander One Professional Pack. В доборе есть MachSol Work Folders для работы с папками |
| аналог TeamViewer | AnyDesk, RuDesktop, АССИСТЕНТ |
| замена AutoCAD | Платформа nanoCAD 26, КОМПАС-3D V25, ZWCAD |
| российский аналог Windows | Astra Linux Special Edition, РЕД ОС, затем системы из раздела импортозамещения |

В каждом из шести ответов показаны четыре карточки. Прямая замена получает причину с названием исходного продукта и разделом. Близкий по классу товар помечается отдельно. Для «Тимвьюер» в подсказках первые три позиции совпали с первыми тремя заменами поиска.

## Как выбирается замена

1. Поиск сверяет написания со справочником, включая кириллицу, версию после имени и небольшие опечатки. Из каждой указанной рекомендации сначала берётся одна карточка, в порядке записи. Вендор уточняет совпадение по названию. Затем поиск добирает из перечисленных разделов с учётом назначения и близости к уже найденной линейке.
2. Для продаваемого товара без записи поиск ограничивает замены его классом. Помогают связи семейств, сходство названий и описаний. Для запроса по одному вендору берётся тот класс, в котором представлено больше всего его линеек. Исходный продукт, дополнения к нему и допродажи исключаются.
3. Название отсутствующего продукта может само подсказать назначение, как в случае «Pro Audio». Если свидетельств недостаточно, fast предлагает выбрать один из трёх ближайших разделов. Примеры берутся только из показанных вариантов. В smart Jev определяет назначение по названию в закрытом списке до 60 классов фида и может выбрать «ни один». Порог принятия — 0,55, ожидание — до 590 мс. Результат кэшируется.
4. Для отечественной замены нужны отметка `russian: true`, раздел с пометкой «(Импортозамещение)» или предложение из реестра. Условие применяется и к добору. Если в допустимом классе всего две подходящие карточки, покупатель видит обе и их количество.

## Проверки

[Регрессионные тесты](../../../tests/test_m3h.py) проверяют все шесть продуктов, порядок рекомендаций, совпадение вендора, российский фильтр, подсказки, малый класс и выбор при неизвестном названии. Подставной транспорт проверяет ширину списка Jev, порог принятия и повторное чтение из кэша.

Для проверки справочника на нужном снимке достаточно запустить `KZ_DATA_DIR=<снимок> .venv/bin/python -m kuznitsa.cli kb-check`. На тестовом фрагменте ошибок структуры нет. Две ссылки дали предупреждения: «Домашняя Фотостудия» и «Bricsys BricsCAD Pro» есть в дереве поставщика, но продаваемые карточки в снимке отсутствуют. Остальные рекомендации этих записей продолжают работать.

| Проверка | fast | smart |
|---|---:|---:|
| Переформулировки M3e–M3g, первая карточка | 77/77 | 77/77 |
| Контроль организаторов | 10/10 | 10/10 |
| p95 полного поиска на контрольных и дополнительных запросах, 29 запросов | 26,1 мс | 14,8 мс |
| p95 по девяти запросам замены | 52,5 мс | 354,1 мс при первом прогоне через шлюз, 45,1 мс с кэшем |
| Dev на демокаталоге | 302/310 | — |

В двух случаях без записи проверен живой шлюз Jev. Для непрозрачного названия «TesselQuill» поиск запросил уточнение, для «QLab 4 Pro Audio» предложил аудиоредакторы. Шесть словарных запросов обошлись без вызовов. На «аналог Kaspersky» без записи в новом справочнике первыми остались Dr.Web Enterprise Security Suite и PRO32 Endpoint Security Advanced.

Полный pytest — 730 тестов прошли за 6 минут 4 секунды. Единственное предупреждение Starlette относится к HTTP-клиенту TestClient.
