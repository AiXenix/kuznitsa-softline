## Маршруты показа

Оба режима проверены через FastAPI TestClient. Для «антивирус на 30 пк» у каждой первой карточки в `score.why` есть объяснение из профиля.

| Клиент | Первая карточка и основание |
|---|---|
| Торговая компания | KES Стандартный. У KSOS предел 25 мест. На 30 рассчитана новая покупка для перехода, поскольку коммерческого SKU апгрейда на этот тираж в прайсе нет. |
| Госклиника | KES Total для госучреждений. В портфеле «KES для Linux» связан с этой редакцией. Предложение подходит под Astra Linux, реестр и ФСТЭК. |
| Университет | Dr.Web Enterprise Security Suite, академическая лицензия на комплексную защиту. Эта линейка уже установлена в вузе. |

Три условия клиники снимаются по отдельности. В fast без ФСТЭК список растёт с пяти до восьми карточек. Снятие только ОС или реестра меняет условия и объяснения. Состав сохраняется, поскольку все оставшиеся предложения удовлетворяют снятому условию. У гостя коммерческие предложения без этих ограничений. Аудитория учитывается также в вариантах внутри карточки.

- По «продл» сначала идут Контур.Экстерн (14 дней), затем КриптоПро CSP (45 дней). По «удаленный доступ» у ИТ-компании первые — RuDesktop Standard и Ассистент Стандартный из отраслевого комплекта. Сопровождение ниже основных лицензий.
- У бухгалтера семь слотов. В слоте учёта — 1С:Бухгалтерия 8. Сначала требуется пригодный вариант с расчётом. Далее учитываются порядок семейств в слоте KB и профиль внутри семейства. Явно названная отрасль уточняет выбор.
- В спецификации клиники подобраны 4/4 строк, включая KES на 50 ПК по марке и портфелю. По `rfcg` первым идёт KES. Для защиты сервера показаны Dr.Web и Kaspersky. Повтор заказа возвращает купленный SKU с действием «Повторить».

## Движок и границы приёмки

Индекс комплектов объединяет алиасы, леммы, опечатки, тексты слотов и локальные эмбеддинги. Fast уточняет неоднозначный запрос. Jev выбирает из восьми записей с порогом 0,55 и может отклонить все варианты. Роль в отрасли сохраняет свои слоты. Поддержаны родительские комплекты и ОКВЭД по самому длинному префиксу. ОКВЭД и наследование проверены на временной KB.

Коды ОКПД2/КТРУ сверяются с предложением поставщика, резервный подбор по классу явно обозначен. Полное название находит конкретный SKU, включая оба импорта D2. Учтены обратные связи импорта, DWG, числа словами, бюджет всей покупки. Спецификация из 200 разных строк заняла 0,082 с с артикулами и 0,225 с без них, прирост пиковой памяти — 3,1 и 7,8 МиБ. Добавлены `meta.labels`, CORS, раздельные лимиты 600/мин, `Retry-After` и авторизация живого `source=eval`.
