# Рецензия M1 · AiXenix

- Для закупщика важнее увидеть подходящий диапазон лицензии, чем заполнить три места в выдаче. Ослабляем фильтры при пустой выдаче. Изменённое условие поясняем. Исключения, требования реестра и сертификатов сохраняем на каждом шаге.
- Дата окончания лицензии в демо должна оставаться актуальной. Источник хранит смещения, при открытии каталога движок привязывает их к переданным часам.
- Синтетические коммерческие варианты допустимы для демо. Реестровый статус и сертификаты нельзя выводить из страны вендора. Частичное подтверждение оставляем неопределённым.
- Десятки тысяч SKU описывают гораздо меньше покупательских задач. Индексируем тексты карточек, проверяем лицензионные условия у предложений. Точный артикул закрепляет конкретный вариант до ранжирования.
- Результаты на меняющейся KB невоспроизводимы без фиксации состава данных. Для регрессии нужен отдельный небольшой набор, для отчёта — замер на фактически сгенерированном каталоге.
