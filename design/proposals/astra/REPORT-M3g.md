# M3g · отличительное слово названия и подбор замен

На исходном `94d81e1` запросы Pixelmator Pro, Shapr3D Pro и QLab 4 Pro Audio выводили Angie PRO. У Ulysses для Mac первой стояла Microsoft Audio Conferencing. В фиде общие слова PRO и MAC могли распознаться как аббревиатуры линеек. Поэтому проверка существования товара теперь учитывает исходное название даже после исправления написания. Редакция, год, версия и платформа сами по себе товар не подтверждают.

Для отсутствующего продукта источник класса — дерево фида, а при отсутствии записи — предметное слово из словаря разделов. Во втором случае покупатель видит подпись «Возможный раздел для замены». У Ulysses название и платформа в быстром режиме не устанавливают назначение. Поиск предлагает уточнить раздел и подбирает варианты по полю платформы поставщика. Добор из соседних разделов отделён от аналогов.

При разборе оборудования поиск проверяет слово устройства вместе с прилагательным до сокращения названия. Год после «выпуск» или «релиз» остаётся частью названия. Английские буквы, произнесённые по-русски, объединяются при подтверждении сокращения каталогом. Перед описанием задачи поиск проверяет название продаваемой линейки в обоих алфавитах.

В `kb/feed_tasks.yaml` у CRM уже был алиас «CRM», у диаграмм — «редактор диаграмм». Добавлена полная формулировка CRM, для диаграмм исправлен порядок разделов. Добавлены названия класса вёрстки и конвертера медиафайлов. Английские термины в словаре помогают предлагать раздел по назначению отсутствующей программы. `kb-check` прошёл без предупреждений и ошибок.

Для 17 запросов проверялись тип ответа, наличие вариантов при отсутствии товара и первая карточка или раздел для присутствующих товаров. На этих запросах в каждом ответе обоих режимов было как минимум четыре карточки. Для smart использовался локальный шлюз. Стоимость на 17 запросах по данным ответов — 0,000168 доллара. Время измерялось после прогрева вокруг вызова `Engine.search` с записью журнала. Закрытый набор измеряет ведущий после слияния.

Полный прогон `.venv/bin/python -m pytest -q` — 710 тестов прошли за 5 мин 53 с. Единственное предупреждение Starlette касается версии HTTP-клиента для TestClient.
