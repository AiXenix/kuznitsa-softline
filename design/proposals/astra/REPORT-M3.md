## Поиск и рекомендации

- Для быстрого поиска индексируются страницы продуктов и классы дерева. Варианты лицензий, исходные коды и фильтры остаются доступны для подбора. У названий страниц приоритет перед общим префиксом SKU, который в фиде часто состоит из одного имени вендора.
- Голое название оборудования открывает класс железа. «Сервер» открывает Rack-серверы, «Windows server» находит Windows Server. Метка «Искали ПО для …?» ведёт к выдаче ПО с запросом и идентификатором раздела ПО. Триггеры, подписи и целевые классы загружаются из 18 записей `kb/hardware_hints.yaml`.
- Для вопросов быстрый режим сопоставляет задачу с продуктами и разделами, включая смысловую близость MiniLM. Jev выбирает из восьми или менее реальных разделов с порогом 0,55. В карточке сохраняется вариант из фида, который подтвердил совпадение.
- На первой странице при недостатке совпадений добавляются четыре товара в сумме. Добор помечен `fill`. Для постороннего запроса предусмотрен отдельный блок «Популярное». Для известного отсутствующего продукта показываются объяснение и замены. Нулевая цена обозначена как «по запросу», отсутствие на складе — «под заказ». Процент скидки считается по действующей и прежней положительным ценам одного предложения.
- Вместе с прежними связями проверены 176 правил Neon‑4. Дополнения в ленте имеют стабильные места и идентификатор правила. Для продуктового запроса до шести рекомендаций выделяются в «Часто покупают вместе». Подсказки от двух символов содержат до четырёх товаров, трёх разделов и двух сопутствующих предложений.
- На Astra Linux в «Часто покупают вместе» попали ALD Pro, защита Kaspersky и RuBackup OneClick. На изолированном журнале реальный модуль B отключил правило Astra → ALD Pro, затем включил его. Обе операции изменили следующий ответ без перезапуска. Поиск и подсказки читают одну версию `kuznitsa.analytics.upsell_rules.active_rules(journal)`. При отсутствии модуля используются правила из файлов. В словаре Neon‑4 загрузчик обнаружил один повтор «схд» и сохранил первую запись.

На вопрос «чем защитить почту» оба режима первым показали UserGate Mail Security. Для проверки контрагента в фиде есть пакет юридических услуг с этой операцией в названии SKU. По запросу «сервер 1С» первым показан Postgres Pro для 1С с пояснением о совместимости. Это СУБД для системы, запрошенной покупателем.

Полный прогон pytest — **432 теста прошли за 4 мин 59 с**. Из них 22 проверки M3 используют выдержку из 55 подлинных предложений фида. Единственное предупреждение относится к версии Starlette TestClient.

## Воспроизведение

Запустить `HF_HUB_OFFLINE=1 .venv/bin/python scripts/check_real_feed.py ПУТЬ_К_СНИМКУ --mode both` в окружении локального шлюза. Команда прогревает индекс, прогоняет 10 контрольных и 19 дополнительных запросов, печатает первые карточки, стоимость, p50/p95 поиска, p95 подсказок и пиковый RSS процесса. Для сравнения стоимости с пустым кэшем решений используйте отдельный каталог данных со ссылками на каталог товаров и дерево фида. HTTP проверен через TestClient.
