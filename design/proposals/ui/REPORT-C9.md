# C9 · Доводка витрины

Снимки Chrome сравнивают исходную витрину `e0be7dc` с рабочей версией C9. В каждой паре совпадают ответ API, запрос, размер окна и точка прокрутки. Для точного воспроизведения цен использованы сохранённые выдачи из журнала тестового стенда. Подсказки получены через GET /api/suggest этого же стенда. Chrome получил страницы и ответы через перехват запросов по каналу DevTools pipe. Дополнительно поиск проверен через TestClient на локальной копии фида. Слушающие порты для проверки не открывались.

## Результаты

1. Сумма осталась крупной и неразрывной. Единица и срок выводятся ниже мелким шрифтом. В Chrome проверены все три строки из замечания на ширинах 1440, 1280 и 390 px. После правки ширина текста каждой цены укладывается в её контейнер. Расчёт с количеством сохраняет перенос перед знаком равенства.
2. Причина занимает до двух строк перед товарной частью. Полный текст доступен при наведении. Иконки привязаны к области товара. На проверенных выдачах «сервер» и «astra linux» пересечений иконок со строками причин после правки нет.
3. Для «astra linux» заголовок показывает «Найдено: 1 · ещё 3 похожих». Рекомендации по правилу учитываются отдельно от похожих товаров.
4. При открытой шестерёнке панель лежит поверх страницы. В кадре 1440 px ширина меню выросла с 888 до 1160 px, горизонтальное переполнение уменьшилось со 139 до 0 px. Пункты меню могут переноситься.
5. Исправления и разделы вынесены в начало списка. Проверены варианты ответа с обеими группами и только с разделами. На ширине 390 px выбор раздела запустил поиск в «Антивирусное ПО» (629), «Офисные пакеты программ Microsoft Office» (1145) и «Ноутбуки» (70824). Выбор исправления также запустил запрос из ответа.
6. Контурный SVG-микрофон остаётся на кнопке во время распознавания и после него. Кнопка сохраняет доступное имя «Голосовой поиск».

**Для потока A.** Тестовый стенд прислал для «ноут» корректный раздел «Ноутбуки», но предложил исправление «windows». Витрина показывает обе группы. Для «офис» исправление было «офисные пакеты», для «антивир» сервер прислал разделы без исправления.

**Проверки:** 64 теста в `tests/web` прошли, `node --check` прошёл для всех файлов JavaScript витрины и браузерных тестов.
