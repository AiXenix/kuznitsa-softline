# C8 · Магазин, быстрый поиск и допродажи

На главной и на странице товара — шапка магазина, каталог, быстрый поиск, избранное, сравнение товаров и корзина. Витрина и виджет используют локальный Inter, бордовый акцент и предоставленный логотип. Баннеры главной взяты из референса. Карточки получают изображения из фида, при сбое загрузки показывают инициалы. Цена по запросу, скидка со старой ценой и поставка под заказ выводятся по данным предложения.

Шестерёнка открывает настройки, профиль, понимание запроса, трассу, сравнение режимов, спецификацию и ссылки ведущего. При входе через /?show=1 Chrome подтвердил автоматическое открытие панели. Поиск при наборе начинается со второго символа. Товар открывает свою страницу, раздел запускает поиск с идентификатором категории. Состав и порядок товаров, добора и рекомендаций приходят от движка.

На /admin#upsell доступны фильтр правил, редактор условий и причин, предпросмотр черновика, включение и выключение, показы, клики и корзины. Использован контракт B. До подключения API на 404 виден подписанный образец списка. Контрактные проверки покрывают обновление, выключение, предпросмотр, отсутствие ключа в обычном пользовательском потоке и загрузку образца.

## Репетиция

Интерфейс ветки ui на базе e50b88f проверен в Chrome на 127.0.0.1:8197. Во временной сборке соединены рабочие версии движка A, API B и файла Neon‑4 с 176 правилами. Из настоящего импорта D взяты 411 предложений из 110 семейств. Это выборка для проверки интерфейса. Запросы выполнялись в быстром режиме через HTTP. Внешние обращения к категоризатору для репетиции выключены.

| Кадр | Результат |
|---|---|
| Главная, шестерёнка | Обычный вход открывает магазин. Панель ведущего открывается из шапки. |
| «astra linux», гость | Одна основная карточка Astra Linux Special Edition, три похожих товара и отдельный блок «Часто покупают вместе». По ограничению 30.5 при одном прямом совпадении движок выдаёт ноль допродаж внутри основной ленты. |
| «сервер», гость | Семь основных результатов, три рекомендации внутри ленты и кнопка «Искали ПО для сервера?». Плитки рекомендаций содержат объяснения из правил. |
| «кас» и «анти» | Для «кас» получены три продолжения, четыре товара и две рекомендации. Для «анти» — шесть продолжений, один товар и два раздела. |
| Счётчики | На правиле hw_server_backup переход на карточку «Кибер Бэкап Старт» и добавление с неё в корзину увеличили клики с 0 до 1 и корзины с 0 до 1. Отдельные показы уже поступили при выдаче. |
| Телефон и виджет | В окне 390 × 844 видны поиск и действия. Ширина документа 375 px с учётом полосы браузера. Проверены товар, выпадающий список и выдача виджета в быстром режиме. |

**Для ведущего.** На «astra linux» показывайте отдельный блок совместных покупок. Для кадра с рекомендацией внутри основной ленты используйте «сервер». После смены снимка каталога состав подбора может измениться.

**Проверки.** 64 теста tests/web прошли. Синтаксис всех модулей web и браузерных тестов проверен через node --check. Живой предпросмотр выполнен без ключа. Записывающие операции редактора проверены на контрактной заглушке. Снимки в c8-screens/, включая отдельные кадры ленты, совместных покупок и предпросмотра правила. Подключение в общих файлах при слиянии не требуется.
