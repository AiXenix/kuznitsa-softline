# C4 · Витрина, консоль и виджет

## Что проверено

На локальной копии `59fc888` прошли оба маршрута `/?show=1` в Chrome при 1366 × 768. В [каталоге снимков](c4-screens/) файлы `short-1…10` и `long-1…19` соответствуют отдельным остановкам панели. Всего сохранено 57 кадров. Проверены все вкладки консоли, галерея, справка, свежий разбор, карточка товара, набор компонентов и виджет. На телефоне 390 × 844 меню читается целиком, действия переносятся, ширина страницы укладывается в окно. Исправлены перенос контекста между независимыми шагами показа, переполнение колонок сравнения и панели действий на телефоне.

В изолированной копии журнала кнопки агента последовательно применили и проверили синоним «адешка». Сохранены кадры [после применения](c4-screens/agent-applied.jpg) и [после проверки](c4-screens/agent-verified.jpg). В [предпросмотре весов](c4-screens/weights-preview.jpg) при марже 50 % API показал 9 сдвинутых позиций и 0 инверсий. Для записи использован только тестовый токен локального процесса.

Все 50 проверок `tests/web` прошли, `node --check` прошёл для каждого модуля. В полном наборе прошли 180 из 181. Потоку B: в `test_fresh_history_paired_and_recovery` доля `before_top5 / labeled` равна 21 790 / 38 828 (56,12 %), тест допускает до 55 %. Исправлен тест витрины «Recovered count differs from API». Плитка получает число из парного прогона и при наличии `kpi.pairs`. Консоль поддерживает готовые строки и цвет изменений, одно общее пояснение, отчёт роли, импорт и очередь раскладки. На живой витрине проверены диапазон 25–49 устройств, экономия на кэше, варианты уточнения и объяснение пустой выдачи. Переход по `kit.parent`, условие ОКВЭД и приоритет `meta.labels` проверены на образцах 27.3–27.6.

[Виджет](c4-screens/embed.jpg) получил подсказки и выдачу через API локальной копии. Голосовой ввод проверен с распознанной фразой «на тридцать компьютеров» и языком `ru-RU`. Запись физического микрофона и установка на независимом домене остаются для интеграционной проверки. Для [загрузки файла](c4-screens/spec-upload-contract.jpg) браузер передал исходные байты; тестовый обработчик добавил сведения о файле к настоящему ответу поиска. В кадре две позиции и пропуск третьей строки. Выгрузки XLSX проверены на договоре. Сквозная проверка книг с листами и итогами требует слияния D и B.

На стыке A/B просьба согласовать идентификатор семейства. Витрина сравнивает ответы `POST /api/search` по `card_id`; обычный режим сейчас отдаёт `sku:<offer_id>`. Маршрут `/api/admin/ui/search-reference?q=…` используется инспектором для перехода к записи журнала и пока возвращает только `search_id`.
