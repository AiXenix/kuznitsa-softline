# C7 · Репетиция финального показа

В новой вкладке откройте `/?show=1`. Финальный маршрут содержит 34 экрана, включая отдельные кадры для смены профиля и действий оператора. Переходы работают стрелками или через список. Для короткого выступления сохранён маршрут на 11 экранов. Сцену приоритетов можно отдельно пройти за пять переходов. Перед началом ведущий вводит свой доступ в консоли. При повторном открытии в той же вкладке панель помнит шаг.

## Что проверено живьём

Chrome прошёл до последнего экрана все три маршрута кнопками. Код движка и консоли взят из `3b76e01`. Защищённый каталог последнего золотого снимка недоступен для чтения из рабочей копии. Для итоговой репетиции взята отдельная копия репетиционных данных потока B. Штатными командами пересобраны история с seed 20261126 на 21.11.2026, парный прогон и предложения. Получены 45 000 поисков, 24 000 сессий, 7 623 парных фразы. Добавлены три штатных примера приоритетов. Первоначальная проверка на старой копии журнала показала предупреждение о несовместимой разметке. Числа итоговых кадров получены после пересборки.

## Что передать A и ведущему

- **«Астра Линукс;50» в спецификации, `gov_clinic`.** Ожидалась лицензия ОС. Первая позиция сметы — «Техподдержка Группы Астра Стандартная». Файл и скачивание работают, подбор этой строки требует проверки A.
- **«антивирус на 30 пк», `gov_clinic`.** Первый результат — Kaspersky Endpoint Security для бизнеса Расширенный, вариант GOV 25–49. На карточке видны реестр и «Без НДС». Метки ФСТЭК на первой карточке нет. Предпросмотр приоритета для этой фразы показал ноль перестановок. Ведущему стоит показать область правила и сравнение, не обещая подъёма конкретной карточки.
- **«rfcg», гость.** Умный режим исправил запрос на «каспер» и вернул 19 результатов. DEMO.md описывает «касп» и одну карточку. Для «yfyjr», `design_bureau`, строка исправления — «нанок», первая подсказка товара — «Платформа nanoCAD».
- **«autocad», `design_bureau`, и «аналог vmware», `ent_factory`.** Первые три замены в репетиции — nanoCAD Базовая, nanoCAD Pro, ZWCAD Professional для AutoCAD; «Брест», Basis Dynamix Standard, zVirt Standard для VMware. Порядок отличается от перечней в DEMO.md.
- **Цифры для защиты.** На репетиционной сборке доля пустых выдач изменилась с 33,3 % до 4,9 %, попадание цели в пятёрку — с 50,7 % до 89,4 %. Агент нашёл 17 предложений. В каталоге 23 538 предложений. На вкладке данных этого снимка нет отчёта последнего импорта. В экономике модели — «ожидаются данные». Для выступления берите цифры с открытого экрана.

## Скорость и материалы

В одном проходе Chrome по локальной копии первый содержательный кадр витрины появился через 36 мс, ссылки с примерами — через 144 мс. Первая загрузка `/api/meta` передала 282 201 байт за 59 мс. В той же вкладке повторная витрина была готова через 81 мс, повторного запроса справочника не было. Первый содержательный кадр консоли появился через 28 мс, пары KPI — через 293 мс. Это наблюдения одной репетиции. Публичный справочник сохраняется на две минуты в sessionStorage; главная загружает модули второстепенных страниц по мере необходимости.
