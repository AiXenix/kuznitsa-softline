# D2 · Чужой каталог, раскладка и самопроверка

**Результат для показа.** 256 SKU вымышленных вендоров, 64 линейки, 32 листовые категории из всех 16 разделов. По независимому от ответов модели эталону локальная раскладка верно классифицировала **52/64 (81,25 %)**, Jev — **61/64 (95,31 %)**. Первый живой импорт через шлюз занял **97,63 с** с построением векторов. 235 вызовов, **0,015594 $**, около **1,56 ₽** при демонстрационном курсе 100 ₽/$. [Сводка оплаченного прогона и примеры решений](longtail-jev-report.json). Повтор с нулевым бюджетом прочитал 235 ответов из кэша, отправил 0 запросов и стоил 0 $.

## Что проверено на импорте

- Через загрузчик БЗ читаются категории, задачи, роли, отрасли и семейства. Основной словарь загружается заново при запуске, кэш векторов зависит от текста. В режиме Jev в этом опыте было 43 вопроса о категории (32 пути, 11 общих или пропущенных категорий у отдельных линеек) и по 64 вопроса о задаче, роли и отрасли. Кандидаты для листовых категорий — до восьми плюс отказ. Ответ модели ниже 0,55 уходит на проверку. Для каждой группы признаков сохраняется максимум один подтверждённый вариант.
- На 22 размеченных линейках локальный режим восстановил 13 эталонных задач и 2 роли. Jev восстановил 21 задачу и 20 ролей. Эталон описывает одну целевую задачу и роль; возможны другие применимые признаки. Отрасли на образце отдельно не размечались. Слабое место локального режима — полнота определения роли по описанию продукта.
- Из трёх ошибок категории Jev дважды оставил виртуальную доску в автокатегории и один раз выбрал управление идентификацией вместо шлюза привилегированного доступа. У всех 256 предложений остались пустыми реестр и сертификаты. Эти поля в автосемействе требуют согласованных явных данных вариантов. Список аналогов сопровождается оценками близости.
- При отказе шлюза оставшиеся промахи кэша обслуживает локальная раскладка. Успешные кэшированные ответы доступны и с нулевым бюджетом. Причины, цены, варианты и оценки выбора сохраняются в журнале и сводке. Испытания бюджета, HTTP 429, порога принятия, параллельности и повторной загрузки используют подменный транспорт.
- 100 000 строк CSV, уникальные артикулы и циклический ассортимент из 64 неизвестных линеек — **34,07 с** при прогретом локальном кэше. Это время включает чтение, приведение к Offer, классификацию и запись всех файлов. При тысячах уникальных семантических описаний время будет зависеть также от первичного расчёта векторов. Круговой импорт всех **23 558** демонстрационных SKU совпал по каждому полю Offer; быстрый dev — **237/310**. Полный pytest — **142 пройденных теста**.

## Самопроверка через Engine.search

Режим fast, seed 7, до 300 предложений без повторения. Выборка выравнивает представительство вендоров и категорий. В ячейках проценты попадания ожидаемого семейства в топ-3 / топ-5. Если проба указывает редакцию, требуется соответствующая карточка. Артикул однозначно задаёт вариант. Пропускаются неприменимые преобразования, например произношение для названий полностью на кириллице.

## Для потока A

1. В обычной ветке data семейство по имени и артикулу ищется по Offer. Для включения его связей нужен загрузчик 26.4 из D1. С подключённым в памяти загрузчиком запрос «защита от шифровальщиков» возвращает Veltari Lumova даже до расширения планировщика, за счёт категории. Проверка веса показала, что план задачи читает список семейств из строки задачи и игнорирует обратную связь из записи семейства.
2. [Дословные вставки в планировщик и маршрутизацию](integration-D2.patch) прошли `git apply --check`. Импорт строит `kb.import_links` при загрузке автозаписей. На реальном поиске с предложенной вставкой кандидат Veltari Lumova получил вес 0,85 вместо 0,65 в плане задачи и вышел первым. Для «аналог Kaspersky Small Office Security» вес этой линейки вырос с 0,55 до 0,85, она вошла в первую двойку. Для ролевого и отраслевого комплекта вставка учитывает импортированное семейство в слоте соответствующей категории.
3. «Чем чертить в dwg» доходит до `off_topic` раньше отбора карточек. При маршрутизации в `task` реальный поиск возвращает две выдуманные линейки `cad_2d`. В патче расширен существующий шаблон «чем …». Ещё два воспроизводимых случая для разбора: точное «Microsoft Windows Server 2022 Standard Russian BOX 16 Core BUSINESS New Perpetual» на XLSX выводит Datacenter; «Onvella Lumonu Облачная инфраструктура IaaS, 10-24 ПК, 12 мес., ESD» на длинном хвосте даёт пустой список карточек.

## Для потока B

При выполнении контракта 26.6 `GET /api/admin/ingest` достаточно вернуть содержимое `import_report.json` под ключом `catalog`. Консоль сможет читать `catalog.ai` без пересчёта. Для текущей функции `ingestion` в `kuznitsa/api/admin.py` дословное добавление перед `return`:

```python
    path = Path(e.journal.path).parent / "import_report.json"
    catalog = json.loads(path.read_text()) if path.exists() else None
```

В возвращаемый `dict(...)` добавить `catalog=catalog`. Для вручную проверяемой очереди использовать строки `import_ai.jsonl`, в первую очередь отказы Jev и решения локального режима с низкой уверенностью. Фактические деньги берутся из `ai.usd`; `forecast_usd` используется только для планирования.
