Таблицы, параметры YML, свойства CommerceML и JSON-атрибуты используют один словарь `mapping.py`. В образцах проверены все названия из задания, включая «Теги-поиска», «Для чего?» и «ЖАРГОН». Поисковые теги из нескольких характеристик объединяются с удалением повторов. Новый ключ `operation` сохраняет исходную формулировку, а распознанное значение продления также попадает в `lic.action`.

В `day_report.md` ведущий видит число заполненных характеристик по ключам и несопоставленные имена с числом предложений. Для каждого образца отчёт показал по пять сопоставлений каждого целевого ключа и «Контур внедрения» у трёх позиций. На одно предложение два разных имени, например «Жаргон» и «Также ищут», дают два сопоставления. Производная копия того же свойства счётчик не увеличивает. В JSON статистика доступна как `day_report.catalog.attributes` и `import_report.attributes`. [Таблица видов цен и команды ведущего](../../../docs/DAYX.md)

## Репетиции и время

Десять прежних открытых наборов прогнаны на базе `544a9d0` и с D7 в режиме `embed`. Число предложений, топ-3 и топ-5 сверены на каждом наборе. В сумме до и после получено 26 предложений и **186 из 190** успешных поисковых проб. На каждом новом образце топ-3 составил 23 из 25. Закрытые E4 и E5 в этот замер не входили.

Полный `day --ai embed` на E1 занял **241,73 с** при ориентире 277 с. Распознаны все восемь файлов, получено 7 003 предложения. При объединении таблиц импорт теперь собирает справочники за тот же проход, что и товары. На паре книг 1С проверено по одному открытию каждой таблицы вместо двух. На E1 импорт и раскладка заняли 28,73 с, история — 109,88 с, повторный поиск — 52,96 с, агент — 33,66 с. Разница полного времени включает влияние нагрузки стенда.

Полный офлайн-прогон `pytest -q` прошёл за 349,04 с. **393 теста прошли**. Тестовый клиент Starlette выдал одно предупреждение об устаревшем интерфейсе.

## Передача потоку A

В `catalog.jsonl` поле `attrs.prices` — объект. Проверка на новом снимке показала, что `kuznitsa.index.source.read_offer` превращает его в строку перед передачей движку. Чтобы потребитель мог обратиться к `offer.attrs["prices"]["gov"]`, в `kuznitsa/index/source.py` замените оба цикла преобразования `attrs` в конце `read_offer` следующим фрагментом.

```python
    for key in ("aliases","certs","extra","prices"):
        value=attrs.get(key)
        if isinstance(value,str) and value.lstrip().startswith(("[","{")):
            try:
                decoded=json.loads(value)
            except ValueError:
                continue
            if isinstance(decoded,dict if key in {"extra","prices"} else list):
                attrs[key]=decoded
    for k,v in attrs.items():
        if not isinstance(v,str) and k not in {"aliases","source_ids","certs","extra","prices"}:
            attrs[k]=json.dumps(v,ensure_ascii=False)
```
